# RAMS 项目 · 数据规范（01）

> 本文件是 `.clinerules/` 下的数据专章，与 `00-核心规则.md` 配合。它定义：数据怎么分层存、字段契约长什么样、清洗脚本 `scripts/build_dataset.py` 的产出契约。
> 一切以"标准数据集 `data/processed/standard.parquet` 是模型唯一数据源"为中心。
> 最后更新：2026-06-08

## 1 · 数据实况（实测，照此处理，勿按旧文档假设）

| 文件（放 data/raw/） | 结构 | 行数 | 列 | 时间 |
|---|---|---|---|---|
| 藻类检测数据_分深度整理.xlsx | 20 sheet（0.5m→10.0m，列名全一致） | **258,542** | 16 | 2021-03-01 → 2025-09-30 |
| 气象数据.xlsx | `Sheet1` 有数据，`Sheet2/3` **空（忽略）** | **232,067** | 8 | 同上 |
| 藻类_气象_最近时刻匹配.xlsx | 仅 0.5m 合并样例，列名带 `_x/_y` | 12,800 | 23 | 同上 |

- 气象采样**确认 10 分钟**（98.8% 间隔为 10min）；藻类约 3 小时。
- 原始 xls 里**测量时间是文本**，读入须 `pd.to_datetime` 显式解析。
- 透光率=100（设备未入水）在 0.5m 层仅 2 条；深层占比 Stage 1 画像再确认。
- 单站点 902。匹配表只作 0.5m 对齐的**校验参考**，不是标准数据集。

## 2 · 三层存储（原始只读 → 中间可重生成 → 标准唯一源）

```
data/
├── raw/                       # 原始，只读、永不修改、永不提交
│   ├── 藻类检测数据_分深度整理.xlsx
│   ├── 气象数据.xlsx
│   ├── 藻类_气象_最近时刻匹配.xlsx     # 0.5m 校验参考
│   └── ORIGIN.txt             # 来源声明（站点已脱敏、采集周期、字段口径）
├── interim/                   # 中间产物，可由 raw 重生成（磁盘紧可删）
│   ├── algae_long.parquet     # 20 sheet 合并的藻类长表（258,542 × 16，含 depth）
│   └── meteo.parquet          # 气象原生 10min（232,067 × 8）
└── processed/                 # 标准数据集 = 模型/训练/分析唯一入口（必须保留）
    ├── standard.parquet       # 对齐+补齐+校验后的规范长表（约 258,542 × 25）
    └── norm_stats.json        # 仅训练集拟合的归一化参数
```
字段契约 `schema.yaml` 放 `configs/data/`（属配置，不放 data）。

格式约定：**Parquet + ZSTD 压缩；数值统一 float32；`timestamp` 为 datetime64；`site_id`/`origin` 为 category**。全量约 26MB，**可全量载入内存，不分块、不分区**。

## 3 · 标准数据集形态与字段契约

**形态：长表（long format）。** 20 个深度 sheet 纵向合并，`depth` 作列保留（**不要做成 20 个宽列**）。后续 `tensor_builder` 按 `(timestamp, depth)` 透视成 `(B,T,D,C)`。

**列名一律英文 snake_case 存**（避免代码/编码/ONNX 中文列名问题），中英映射记入 schema.yaml。

### 键与维度（3 列，不计入特征通道）
| 中文 | 英文 | 类型 | 说明 |
|---|---|---|---|
| 站点编号 | `site_id` | category | 单站，按字符串存 "0902"（保留前导零） |
| 测量时间 | `timestamp` | datetime64 | 显式解析；时序主键 |
| 深度 | `depth` | float32 | 0.5–10.0，长表空间维 |

### 水质 13 通道（来自藻类表）
| 中文 | 英文 | | 中文 | 英文 |
|---|---|---|---|---|
| 水温 | `water_temp` | | 黄色物质 | `cdom` |
| 透光率 | `transmittance` | | 绿藻细胞数 | `green_cells` |
| 绿藻浓度 | `green_conc` | | 蓝藻细胞数 | `cyano_cells` |
| 蓝藻浓度 | `cyano_conc` | | 硅藻细胞数 | `diatom_cells` |
| 硅藻浓度 | `diatom_conc` | | 隐藻细胞数 | `crypto_cells` |
| 隐藻浓度 | `crypto_conc` | | 总细胞数 | `total_cells` |
| 总浓度 | `total_conc` | | | |

### 气象 6 通道（来自气象表）
| 中文 | 英文 | | 中文 | 英文 |
|---|---|---|---|---|
| 风速 | `wind_speed` | | 温度 | `air_temp` |
| 风向 | `wind_dir` | | 湿度 | `humidity` |
| 压力 | `pressure` | | 降雨量 | `rainfall` |

### 物理推算补齐 4 通道（清洗时计算，C 19→23，schema 标 `source: augmented`）
| 字段 | 英文 | 推算依据 |
|---|---|---|
| 溶解氧 | `dissolved_oxygen` | 水温反相关（氧饱和度方程） |
| pH | `ph` | 总藻浓度（光合耗 CO₂） |
| 悬浮物 | `suspended_solids` | 透光率反推 |
| 太阳辐射 | `solar_radiation` | 气温日较差 + 月份 |

### 溯源列
| 列 | 类型 | 说明 |
|---|---|---|
| `origin` | category | 行级来源；v2.0 全为 `real`（不注入合成行），列保留备扩展 |

> 13 水质 + 6 气象 = **19 实测通道**，+4 推算 = **23**，与 `C=23` 一致。`site_id/timestamp/depth` 是键/维度，不计入通道。
> **风向 `wind_dir` 按原始角度（0–360）存**；sin/cos 圆形编码放到 `tensor_builder` 做，标准数据集保持干净规范值。

## 4 · 清洗与对齐流程（build_dataset.py 内部）
```
20 sheet 藻类 ──纵向合并(加 depth)──→ algae_long(258,542×16)
气象 Sheet1 ───────────────────────→ meteo(232,067×8, 原生10min)
                    │
        merge_asof(on=timestamp, direction='nearest')   # 每条藻类配最近气象
                    ↓
        透光率==100 标记 → KNN/前后向插值
                    ↓
        4 个缺失字段物理推算补齐
                    ↓
        中文列名 → 英文 snake_case
                    ↓
        类型固化(float32 / datetime64 / category) + Pandera 校验
                    ↓
        写 data/processed/standard.parquet
```
**0.5m 校验**：对 0.5m 层做完 merge_asof 后，结果应与 `藻类_气象_最近时刻匹配.xlsx` 逐行一致（验证对齐逻辑正确）。

## 5 · 归一化与切分的存储

- **归一化不写进 parquet**：standard.parquet 存"干净但未归一化"的规范值，归一化在加载时做。
- **只用训练集拟合**归一化参数（按通道均值/标准差），存 `data/processed/norm_stats.json`，再用同一组参数变换 val/test（防泄露）。
- **不存三份拆分文件**：standard.parquet 按 `timestamp` 排序保存，train/val/test 在 `DataModule` 按时间 **70/15/15 确定性切分**（切分边界写进 `configs/data/`）。

## 6 · build_dataset.py 产出契约（落地清单）

- 输入：`data/raw/` 的 3 个 xlsx。
- 输出：
  - `data/interim/algae_long.parquet`（可选）
  - `data/interim/meteo.parquet`（可选）
  - `data/processed/standard.parquet`（**必须**，模型唯一数据源）
  - `data/processed/norm_stats.json`（训练集拟合）
  - `configs/data/schema.yaml`（字段契约：中英映射/类型/范围/单位/source 标签）
- 约束（呼应核心规则）：此脚本是**唯一接触 xls 的地方**，**只跑一次**；Cline 写好 + 冒烟通过即停，由人跑全量；下游一律只读 standard.parquet。
