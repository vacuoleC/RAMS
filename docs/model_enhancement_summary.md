## 1. 核心结论（一句话）

**藻类是强自回归过程，模型的正确形态是"预测偏离而非水平"**——目标用绝对增量 Δ，区间用 Δ 的分位数，输入含浓度历史，多任务保校准，CRPS+滚动窗口评估。

## 3. 已证伪/排除的方向（诚实记录）

| 方向 | 结果 | 结论 |
|---|---|---|
| 换框架（TFT/PatchTST 等） | 全更差 | GRU 多任务已最优 |
| 去量纲化（log/相对） | 部分修复校准、CRPS 打平、方向未修 | 保留 abs_delta |
| wind_u 交叉特征 | 增量下 +1.24% 更差 | wind 通道关闭 |
| 分层趋势喂增量 | 相关≈0，模型无增益 | 物理链在单站不成立（M5+E 互补证据） |
| 递归预测 | 长视界误差累积 | 用直接多步 |
| 分布漂移后处理修复 | 5 方法全失败 | 年际状态漂移，后处理修不了 |
| 专用方向头 | +0.003 AUC 无增量 | 判别信息已在分位数里 |
| 共形 90% 目标 | 宽 +26% 只换 0.851 | 不值 |

## 4. 已知局限（诚实标注）

1. **方向判别弱**（AUC 0.59）——可做软信号（高置信阈值），不可做硬方向预测
2. **区间窗口漂移**（std 0.09，逐窗口 0.66~0.94）——年际非平稳的固有属性，后处理校准修不了；真修需分布预测+年际正则（未来方向）
3. **藻类增量的可预测信号主要来自自回归**（M5 τ=1 r≈0.63）——气象/物理驱动弱，这是数据本质
