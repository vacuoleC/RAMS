## 摘要

本报告记录 RAMS（水库藻类监测）项目在"追求最大精度"目标下，从发现评估协议缺陷到建立完整模型形态的全过程探索。探索覆盖 20+ 个方向，经历了五个阶段：认识数据缺陷 → 建立增量预测主线 → 系统验证 A-H → 追问短板与底层问题 → 触及数据信息上限。**最终结论**：模型已接近该单站数据的可预测信息上限（纯自回归已达最优），继续调模型/特征是浪费；预警应从"预测未来"转向"诊断当前"；再压误差需靠数据量/多站而非模型。

**核心成果**：
- 发现并修正评估协议 bug（固定 70/15/15 切分的方差失配）
- 确立增量预测（Δ）为主线的模型增强方向（全视界超越持久化）
- 用信息上限探针量化了数据的可预测边界
- 建立可计算的藻华事件定义（12 个真事件）
- 形成正式模型完整形态（增量 + 日级 + 多任务 + 藻华状态预警）

---

## 1. 背景与动机

### 1.1 项目定位
RAMS 是水库藻类智能监测系统，目标从"轻量可部署"变为**追求最大精度 + 真实科研 + 五任务全做**（M1 浓度预测/M2 热分层/M3 点位优化/M4 预警/M5 因果时滞）。算力充足（sensecore H100，可扩容 8×H100）。

### 1.2 探索的起点
2026-08-09 完成五任务的基础探索后，进入"模型是否可行、有无更好框架"的讨论。T2 占坑子代理发现了一个**重大 bug**：持久化基线取错了列（取水温而非浓度），导致"模型比持久化好 67%"是误算。真实对比下，模型 RMSE（3.44~3.64）反而不如平凡持久化（1.24）——但这主要是**评估协议不公平**（固定 70/15/15 把高波动段训练、低波动段测试），不是模型无用。

这一发现启动了系统性的模型增强探索。

## 2. 探索方法论

### 2.1 探索政策
采用 `exp/EXPLORATION_POLICY.md` 政策：每个方向独立目录（`exp/<task>/`）+ `rethinking.md`（思考）+ `trydoing.jsonl`（执行）+ `whatwedo.md`（事件）+ `lossing.md`（边界决策），git 原子提交，本地↔算力机双同步（`sync_sensecore.py`）。

### 2.2 统一协议（关键）
所有探索共用**同一评估协议**，保证可横向对比：
- 滚动窗口：训练 730 天 / 测试 90 天 / 步长 45 天，17 窗口（替代有 bug 的固定切分）
- 指标：CRPS（逐视界）+ RMSE（还原原始单位）+ 区间覆盖率
- 目标口径：增量 Δ = conc_{t+h} − conc_t（B1 确立）
- 3-seed 均值±std，Wilcoxon 显著性

协议一致性经反复验证（各实验 base arm 逐位复现 B7，CRPS 0.8912/持久化 1.1281 完全一致），保证结论可信。

## 3. 第一阶段：认识数据缺陷

| 探索 | 发现 |
|---|---|
| **T4 评估协议** | 固定 70/15/15 把高波动段（2021-24, std=13.9）训练、低波动段（2025, std=3.1）测试，协议不公平。改用 CRPS + 滚动窗口。 |
| **T4 关键洞察** | 模型输入缺浓度历史，持久化先天占优。加浓度历史后模型超持久化 +18.8%。 |

**转折**：藻类浓度是强自回归过程（M5：τ=1 r≈0.63），预测的难点在"偏离"不在"水平"。这奠定了整个探索主线。

---

## 4. 第二阶段：增量预测主线（B1/B2/B7/C4）

| 方向 | 结论 | 关键数字 |
|---|---|---|
| **B1 增量预测** | 目标改 Δ=conc_{t+h}−conc_t，全视界超持久化 | RMSE -2~4.8%，CRPS -28~37% |
| **B2 增量分位数** | 区间改 Δ 的 p10/p90，校准显著更好 | 覆盖率 0.824 vs 绝对 0.669 |
| **B7 去量纲化** | log/相对变化不必要 | CRPS 打平，方向未修，保留 abs_delta |
| **C4 递归预测** | 长视界误差累积崩盘 | h8 递归 +149%，用直接多步 |

**主线确立**：预测"偏离而非水平"——目标用绝对增量 Δ，区间用 Δ 分位数。这是数据自回归本质的正确建模。

---

## 5. 第三阶段：系统验证（A-H）

在增量主线基础上，并行验证 8 个方向：

| 方向 | 结论 | 关键数字 |
|---|---|---|
| **框架比较（C2）** | GRU 多任务已最优，不换框架 | 12 模型对比，TFT/DLinear 更差 |
| **A 增量×多任务** | 多任务叠加"校准"非"精度" | 覆盖 0.672→0.806，CRPS 略稀释 |
| **B 方向概率** | 方向是弱判别（修正 0.53 判断） | AUC 0.59，做软信号 |
| **C 跨 seed 集成** | 边际值得，非刚需 | CRPS -2.4%，5× 算力 |
| **D wind_u 交叉** | 增量下证伪（对比 T1 绝对口径） | +1.24%，wind 关闭 |
| **E 分层趋势** | 物理链不成立（负结果） | 相关≈0，模型无增益 |
| **F 共形校准** | cqr α=0.2 免费值得加 | 覆盖率 0.81，CRPS 持平 |
| **G 分布输出** | 采纳 q9（9 分位） | CRPS +2.0%，一行改动 |
| **H 漂移修复** | 漂移不可后处理修复 | 5 方法全失败，年际非平稳 |

**已排除**：换框架、去量纲化、wind_u、分层趋势、递归、漂移后处理、专用方向头、90% 共形。

---

## 6. 第四阶段：短板与底层问题

在"完成"里找"没完成"，识别 5 个短板，追问 3 个底层问题：

### 6.1 短板批次（I/J/K）
| 方向 | 结论 |
|---|---|
| I 全剖面预测 | 轻微拖累表层（+1.92%），保持表层单层 |
| J 慢变量特征 | 不加（伤方向+精度），但确认方向弱是数据上限 |
| K 两阶段训练 | ts_freeze 精度最优（CRPS 0.808，比单任务低 5.7%） |

### 6.2 底层问题批次（L/M/N/O）
| 方向 | 底层问题 | 结论 |
|---|---|---|
| **L 采样尺度** | 采样 vs 过程尺度 | 日级 + 1-7 天视界胜出（-37% CRPS@24h） |
| **N 藻华识别** | 真藻华 vs 数据尖峰 | **12 个真事件**，2-3 周前置窗口，可计算定义 |
| **O 多层联系** | 深层信息有没有独立价值 | 深层解耦（暴发期 -0.07），垂向迁移证伪 |
| **M 信息上限** | 数据可预测上限在哪 | **接近上限，纯自回归已达最优** |

### 6.3 M 探针的决定性回答
给模型 1-7 天真实未来轨迹，1 天前预报 CRPS 无法降到 0.95 以下（反而略升）。**数据里没有更多可预测信息**。纯自回归（ar_only 0.872）< 全特征（0.949）——温度/气象/深层特征是噪声。

## 7. 最终结论与正式模型形态

### 7.1 核心判断
> **模型已接近该单站数据的可预测信息上限。** 增量自回归主线已提取了大部分可预测信息，其余特征均为噪声。继续调模型结构/特征是浪费时间。**再压误差需走数据量/多站方向。**

### 7.2 预警范式转变
从"预测未来暴涨"转向"诊断当前风险"：
- M 探针证明未来暴涨不可预测（oracle 无提升）
- N 证明藻华是少数明确事件（12 个，2-3 周前置）
- **预警聚焦"当前浓度风险分级"（M4）**，而非"预测未来 24h 浓度"

### 7.3 正式模型形态（全部实证支撑）
| 模块 | 决策 | 证据 |
|---|---|---|
| M1 目标 | 增量 Δ（abs_delta） | B1/B7 |
| 采样尺度 | **日级（T=30，H=7 天）** | L |
| 预警对象 | **藻华状态定义**（顶层带+多层） | N |
| 训练 | ts_freeze 两阶段（冻结 backbone） | K |
| 分位数量 | q9（9 分位） | G |
| 区间 | Δ 分位数 + CQR 校准（α=0.2） | B2/F |
| 输入 | 0-5m 带（压缩冗余层）+ conc_t | O/N |
| 已排除 | 深层/气象/慢变量/全剖面/递归/换框架 | 多重证伪 |

## 8. 科学价值

### 8.1 负结果的价值
本探索的多数方向是**负结果**，但它们构成了扎实的证据链：
- M5（因果）+ E（物理链）+ O（结构）**三重解释了"为什么深层无用"**（暴发期垂直解耦 -0.07）
- M 探针**量化了数据上限**（oracle 无提升）
- 诚实否定了多个物理假说（垂向迁移、分层驱动、气象驱动）

### 8.2 可发表的方法贡献
- 信息上限探针方法（oracle 输入 + 已知段掩蔽 + 视界防退化）
- 藻华事件可计算定义（持续 + 整层联动）
- 单站强自回归数据的最优建模范式（增量 + 日级 + 诊断当前）

### 8.3 诚实标注的局限
- 单站数据的信息上限是硬约束（换数据才有突破）
- 方向判别弱（AUC 0.59，数据本质）
- 区间窗口漂移（年际非平稳，后处理修不了）
- 暴发年际不平衡（2021 主导 74%，泛化受限）
