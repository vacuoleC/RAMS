# RAMS 站位提升行动计划（Standing Plan）

> 最后更新：2026-08-09
> 定位：把"单水库课程作业"抬成一条可发表、可落地、可申报的完整故事线

---

## 核心定位

> **以不确定性量化为贯穿主线，以预测驱动的布点优化为标志性创新，以业务分级预警为落地出口。**

所有动作向这个定位收敛。三条主线共用同一套不确定性机制：
1. **主线**（小样本稳健 DL + 不确定性量化）——可行性高、是综述点名的缺口
2. **标志性创新**（预测误差驱动的布点优化）——无人占据的空白
3. **出口**（预警分级对接 GB5749/WHO/地方预案）——命中真实业务刚需

## 短期（开工前，1-3 天可启动）

### S1. 占坑：建立公开对比基准与迁移实验环境
- 报名 **EFI-USGS 河流叶绿素预测挑战赛**（持续开放、数据公开）
- 下载 **太湖 THQBCA 数据集**（Zenodo，Scientific Data 2024）和**江西水库数据集**（Scientific Data 2026）
- 复现 **Tick Tick Bloom 冠军方案**（arXiv 2505.03808）
- **预期产出**：可复现迁移实验脚本 + 3-5 个公开基线结果

### S2. 定论文蓝图与投稿路线图
- 主攻 **Ecological Informatics**（2区Q1、IF 8.5、方向对口）
- 冲刺 **Water Research**（1区、IF 12.4，需强泛化+机理成型后）
- 保底 **Harmful Algae**（领域最对口、接收率高）
- **预期产出**：一页投稿路线图

### S3. 保密合规与去标识化方案定版
- 制定《数据合规检查清单》：发表/开源/竞赛只出特征级与去标识化结果
- **涉密数据训练 + 公开数据验证**双轨实验设计
- **预期产出**：数据合规清单 + 双轨实验规范

### S4. 撰写"研究空白 + 垂向分层 DL 窗口期"论证
- 水库相对湖泊/海洋研究系统性不足（USGS 162 篇河流建模综述仅 1 个北美 HAB 模型）
- 深水水库"垂向分层+DL"是已证明可行、远未成熟的窗口期
- **预期产出**：开题报告"研究意义+创新点"章节

## 中期（项目推进中）

### M1. 主线方法论：小样本/不平衡 + 不确定性量化
- 物理约束/分层先验、类别不平衡下的预警训练、MC-Dropout/集成/贝叶斯 NN 输出水华概率与置信区间
- GP/KNN/XGBoost 全纳入 baseline
- **状态**：分位数输出已验证（覆盖率 85%），见 architecture_blueprint.md

### M2. 标志性差异化：预测误差驱动的垂向布点优化闭环
- 用"分层观测驱动的预测不确定性/信息增益"作为布点目标函数
- 回答"深度方向布几层、布哪、何时采"
- **状态**：架构设计就绪（见 3.4），待实现

### M3. 业务化落地与对外对标
- 以"单水库可部署预警决策系统"交付，对标 NOAA HAB-OFS
- 预测映射到 GB 5749 / WHO 两级预警 / 地方三级预案阈值，输出"提前量"
- 命中水务取水口刚需与水利"四预"考核

### M4. 公开数据迁移验证（持续）
- EFI 河流叶绿素（时序同构）、太湖/江西水库（中文水库）、LAGOS-US（大样本）、CyAN/CGLS（遥感）

## 长期（完成后）

### L1. 论文矩阵化收割
- Ecological Informatics 主攻 → Water Research 冲刺 → Harmful Algae 保底
- 中文成果投湖泊科学衔接结题；AI for Science Workshop 用"小模型+单站点轻量部署"

### L2. 软著 + 行业标准 + 公开基线沉淀
- 对标韶关"水华预警系统"申报软著；参与地方/水利行业标准起草；公开基准工具沉淀开源

### L3. 沉淀可复用模板
- "监测-预警-处置闭环"整理成站点级预警方案模板

## 总体判断

**最该把资源押在"以不确定性量化为贯穿主线、由它驱动的垂向布点优化闭环"上**：
- 主线（小样本稳健 DL + 不确定性量化）——可行性高、综述点名缺口，**已部分验证**
- 标志性创新（预测误差驱动的布点优化）——无人占据的空白
- 出口（预警分级对接 GB5749/WHO/地方预案）——命中真实业务刚需
- 三者共用同一套不确定性机制，一条故事线同时命中学术站位、数据形态与落地价值
