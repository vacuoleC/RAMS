## 1. 做了什么

将 RAMS 数据管线从 3h 原网格升级到**日级（1D 均值聚合）+ 藻华状态定义**，
重建 `rams/` 下被清理删除的正式数据代码，并补齐单元测试与兼容层。

设计全部来自冻结的探索结论：
- **日级尺度**（`exp/model_enhancement/l_daily_scale/results.md`）：T=30 天回看 / H=7 天视界 / 日平均浓度目标 / 增量 Δ 口径。
- **藻华状态**（`exp/model_enhancement/n_bloom_identify/results.md`）：顶层带(0.5-3.0m)中位数 > 带 p90，且 0.5-5.0m ≥3 层 > 各自 p90，连续 ≥2 天，间隔 ≤1 天合并。
- **M3 选层**（`docs/m3_sensor_placement.md`）：M3 只做部署建议，正式输入保持 20 层；`M3_RECOMMENDED_DEPTHS=(1.5, 5.0, 8.5, 9.5, 10.0)` 供部署对照/瘦身。
- **滚动窗口**（T4 协议）：训练 730d / 测试 90d / 步长 45d / 17 窗口，窗口按日历日对齐。

## 3. 冒烟结果（standard.parquet 全量）

### 3.1 日级张量（全量，20 层全输入）
- `X`      ：`(1601, 30, 20, 2)` —— B=1601 预测日，T=30 天回看，D=20 层，C=2 通道 [conc, temp]，float32 无 NaN
- `X_flat` ：`(1601, 30, 29)` —— 展平特征（20 温 + 6 气象 + 2 分层 + 1 目标浓度）供 GRU 兼容
- `y_abs`  ：`(1601, 7)` 未来 7 天表层浓度（**原始 conc 单位**）
- `y_delta`：`(1601, 7)` 增量 Δ=conc_{t+h}−conc_t（校验 max|Δ−(y_abs−cur)|=0）
- `cur`    ：`(1601,)` 预测日浓度；`dates`：2021-03-31 ~ 2025-09-22
- `bloom`/`strat`：`(1601,)` 藻华状态标签 + M2 分层标签
- 训练段归一化：`fit_stats` 用训练段（首窗口 730d）拟合均值/方差，特征 z 归一化，目标保持原始单位（防泄漏）

### 3.2 藻华状态标签（N 定义，日级口径）
- 全量逐日信号：**115 藻华状态日 / 1638 日（7.0%）**，band_p90(训练段70%)=21.4
- 逐年：2021 年 97 天（32.6%）、2023 年 18 天（5.0%）、2022/2024/2025 ≈ 0 —— **与 N 探索"2021 主导 + 2023 次峰"的结论一致**（3h 口径 159.9 藻华日 / 12 事件）
- 事件（连续 ≥2 天，间隔 ≤1 天合并）：**5 个**，含 2021-03-30~06-28 主事件（91 天）、2023-04 事件（15 天）等
- 首滚动窗口（训练段拟合阈值）：band_p90=33.2，窗口内正例 73/762，训练段 71/675，delta_scale(训练段 Δ std)=9.03（原始单位）
- 差异归因：日级均值聚合稀释了日间涨落，且 p90 阈值在日级分布上更高，因此日级口径藻华日 < 3h 口径（~159.9 日）——事件时间分布（2021/2023 主导）完全对齐，定义本身正确

### 3.3 M3 选层输入（5 层子集）
- `X`：`(1601, 30, 5, 2)`；`X_flat`：`(1601, 30, 14)`（5 温 + 6 气象 + 2 分层 + 1 目标浓度）
- 层：1.5 / 5.0 / 8.5 / 9.5 / 10.0 m

### 3.4 滚动窗口（T4 协议）
