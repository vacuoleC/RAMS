## 1. 做了什么

重建磁盘清理时删除的正式模型与训练代码（`rams/models/`、`rams/training/`），
把五头整合探索结论落地为可训练代码，接上 mdl-data-scale 已就位的日级数据管线。

设计全部来自冻结的探索结论：
- **增量目标**（B1）：M1 预测 Δ=conc_{t+h}−conc_t，评估时还原 conc_t+Δ。
- **q9 分位数**（G）：M1 输出 9 个固定分位数 [0.05,0.10,0.20,0.35,0.50,0.65,0.80,0.90,0.95]，
  比 3 分位 CRPS +2%（点数效应）。
- **多任务**（A）：M1+M2+M4，w=1/3/2；M4 标签支持藻华状态（N 定义）与峰值分位两口径。
- **两阶段**（K）：Stage1 单任务 M1（默认 20ep）→ Stage2 冻结 backbone 微调多头（默认 10ep，ts_freeze）。
- **GRU backbone**（框架比较）：最优，不换；hidden 可配（默认 64）。
- **评估协议**（T4）：滚动窗口 730/90/45 + CRPS（q9 分段线性闭合形式 / 3 分位兼容）+ 覆盖率。

### 6.1 训练配置（冻结设计，与探索 K 同源协议）

- 数据：`DailyTensorBuilder`（T=30 回看 / H=7 视界 / 1D 均值聚合），滚动窗口 730d 训练 / 90d 测试 / 步长 45d / 17 窗口（d0=2021-03-01）
- 目标：增量 Δ=conc_{t+h}−conc_t（窗口训练段拟合 delta_scale 归一化，评估还原 conc 单位）；M4 标签 mode=**bloom**（N 定义藻华状态，冻结设计口径，二分类）
- 模型：`RamsNet`（GRU hidden=64 + M1 q9 分位 [0.05,0.10,0.20,0.35,0.50,0.65,0.80,0.90,0.95] + M2 分层 + M4 预警）
- 训练：`Trainer.fit_two_stage` —— Stage1 单任务 M1（20ep）→ Stage2 冻结 backbone 微调多头（10ep，ts_freeze）；batch=128，Adam lr=1e-3
- 规模：**3 seed（0/1/2）× 17 窗口 = 51 次两阶段训练**，全量完成，总耗时 **109s**（H100）
- 收敛：各窗口 Stage1 loss 0.16→0.08 量级、Stage2 loss 3.1→1.1 量级，正常下降

### 6.7 与探索 ts_freeze（+28.4%）对比

- 探索 K（3h 网格 T=24/H=8，M4 peak_quantile 4 级）：ts_freeze CRPS 0.808 / 覆盖率 0.704 / 技能 +28.4%
- 正式 v020（日级 T=30/H=7，M4 bloom 二分类）：CRPS 1.182 / 覆盖率 **0.776** / 技能 **+21.9%**
- **差异归因（预期内，非回退）**：
  - **协议尺度不同**：正式为冻结的日级协议（H=7 天，持久化基线更易→技能天然低于 3h 网格 H=8 口径）；探索 K 为 3h 网格（H=8）。两者持久化 CRPS 基线不同，技能绝对值不可直接比较。
  - **CRPS 绝对值不可直接比**：日级 conc 单位均值高于 3h（日级数据更平滑、持久化基线 1.512 vs 探索 1.128），但**相对技能 +21.9% 单边高于验收线 +20%**，且全部 7 视界、3-seed、15/17 窗口 >+15%（w3/w5 最低 +15~17%）。
  - **覆盖率反超**：0.776 vs 探索 0.704（+7.2pp）——M4 换 bloom 二分类 + 日级协议 + M4 逆频率权重共同抬升了区间校准，更接近 80% 目标。
