# F 共形校准 · 探索标记（whatwedo.md）

- **标记时间**：2026-08-10（东八区）
- **任务**：F 共形校准（一次探索，用户指定先跑一次）——exp/model_enhancement/f_conformal/
- **背景**：B2/B7 增量分位数模型（Δ=conc_{t+h}-conc_t 的 p10/p50/p90）覆盖率 0.79-0.82，
  接近目标 80% 但"碰运气"（无统计保证，逐窗口漂移 0.48-0.95）。不确定性量化是站位主线，
  共形校准让区间覆盖率有**有限样本统计保证**（审稿人认可）。
- **探索依据**：exp/EXPLORATION_POLICY.md（文件级探索标记）
- **方法**：split conformal（最简单、可证），扩展 B1/B2 滚动窗口协议加 30d 校准段
  （训练 730d / 校准 30d / 测试 90d / 步长 45d，17 窗口）；在归一化 Δ 空间校准
  （affine 可逆，conc 单位保证等价）；Q=⌈(n+1)(1-α)⌉ 阶统计量（有限样本校正）；
  每视界独立校准（n_cal=240/视界）。4 方法对照：raw（B2 基线）/ abs50 / symabs / cqr
  （Romano 2019，下上分开校准）。目标 α=0.2（80%）与 0.1（90%）。
- **产物**：
  - `run_f.py`（实验脚本，冒烟通过，含校准段 raw 覆盖率诊断）

  （仅 import 复用）
- **状态**：✅ 探索完成（2026-08-10 12:45，H100 全量 17 窗口 × 30 epoch，12.1 分钟）
- **结论摘要**：共形校准**均值已准但稳定保证没兑现**——raw α=0.2 覆盖均值本就 0.8003 精确命中目标（B2/B7 的"碰运气"是窗口 std 0.090 而非均值偏差）；cqr（Romano 2019）在 α=0.2 **零成本微改善**（覆盖 0.8077、std 0.086、宽 +2%、**CRPS 与 raw 完全持平**），但**没有降低窗口间漂移**（逐窗口仍 0.66~0.94）——根因是校准段/测试段季节分布漂移（corr=0.339，cqr 只在校准段同样欠覆盖的窗口生效）；对称共形变体（abs50/symabs）反而把窗口 std 抬到 0.126（+40%）且极端欠/过覆盖；α=0.1（90%）够不着（cqr 0.851、仅 4/17 窗口达标、宽 +26%）。详见 results.md。
- **边界决策**：α=0.2 的 cqr 值得作为"有限样本保证层"集成（零成本、可对审稿人讲有限样本保证，但不解决漂移）；α=0.1 不值；对称变体弃用；真正修复漂移需按季节分段校准/更大校准段（后续方向）——待主会话审核
