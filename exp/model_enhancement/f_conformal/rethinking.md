# F 共形校准 · 思考记录（rethinking.md）

## 任务意图
B2/B7 增量分位数模型（Δ=conc_{t+h}-conc_t 的 p10/p50/p90）覆盖率 0.79-0.82，接近目标 80%
但**碰运气**——不是统计保证（每窗口 90d 测试段样本有限，真实覆盖率逐窗口漂移，
如 B2 逐窗口 0.483~0.950）。不确定性量化是站位主线，共形校准的价值在于让区间覆盖率
有**有限样本统计保证**（审稿人认可）。本次是一次探索（用户指定先跑一次），重点回答：
共形校准能否让覆盖率**稳定**到目标水平、区间宽度膨胀多少、CRPS 成本多少、值得集成吗。

## 方法设计决策
1. **Split conformal（最简单、可证）**：每窗口内训练 730d 拟合分位数模型 → 紧邻 30d
   作校准集算 conformal scores → 90d 测试集校正区间。不需要重训模型，校准只是
   scores 的排序统计量（瞬时成本）。
2. **共形空间**：在**归一化 Δ 空间**做（与 B1/B2/B7 的增量目标尺度一致）。对 y=Δ/scale，
   "conc_t + y·scale 落在 [cur+low·scale, cur+up·scale]" 与 "y∈[low,up]" 等价，因此
   覆盖率保证在 conc 单位同样成立（affine 可逆）。
3. **有限样本校正**：Q = 校准集 score 的 ⌈(n+1)(1-α)⌉ 阶统计量（非 naive 分位数），
   split conformal 的交换性假设下给出有限样本保证 P(覆盖率≥1-α)≥1-δ。
4. **三个校准变体**（覆盖"对分位数模型做共形"的常见做法）：
   - abs50：|Δ−p50| 的单侧 quantile，区间 [p50−Q, p50+Q]（对称绕中位数）
   - symabs：max(p10−y, y−p90)，双侧 ±Q 平移原区间
   - cqr（Romano 2019）：下/上分开校准——low=max(p10−y,0)、up=max(y−p90,0)，
     [p10−Q_low, p90+Q_up]（最贴近"非对称分位数区间"的结构）
5. **每视界独立校准**：Q_h 逐视界算（h=1..8 不确定性尺度不同），n_cal=240/视界。
6. **CRPS**：校准只调外沿、保 p50；强制 q10≤p50≤q90 排序后喂 3 分位数 CRPS 闭合形式，
   与 B2/B7 同一实现、同一 conc 单位、可直接比较。

## 预期与反预期
- 预期：共形把覆盖率拉向目标（α=0.2→≈0.80），cqr 最稳（结构最贴近分位数区间）、
  abs50 最保守（对称绕中位数丢弃了 p10/p90 的不对称信息）。
- 反预期（关键风险）：**校准段与测试段分布漂移**（非交换性）。校准段是紧邻测试段的
  30d——若校准段落在高波动期（如春末藻华爆发）而测试段在相对平静期，校准 scores 会
  被极端残差拉大，区间暴涨，测试段覆盖率远高于目标（如 >0.95）。这是滚动窗口 split
  conformal 的已知弱点，本次要看它在 17 窗口上有多普遍。
- 若漂移严重 → 覆盖率"稳定"但不"紧"（都往上飘），需要评估是否值得：cqr 若只微膨胀
  就值得，abs50/symabs 若暴涨就不值。

## 指标口径备忘
- 覆盖率：真实 conc 落在校准后 [low,up]（还原 conc 单位）的比例。目标 α=0.2→0.80、0.1→0.90。
  **重点看跨窗口 std**（"稳定到目标"=均值接近目标 + std 小）。
- 区间宽：Δ 单位（conc 单位），校准前 vs 校准后膨胀比例。
- CRPS：conc 单位 3 分位数闭合形式；vs raw 的相对变化（校准只动外沿，p50 不变，
  CRPS 变化主要来自区间宽）。
- 附加诊断：**校准段自身 raw 覆盖率**——解释膨胀机制（校准段欠覆盖 → Q 大 → 膨胀）。

## 待实证问题
1. 校准后覆盖率是否**均值**接近目标（0.80/0.90）？
2. 是否**稳定**（窗口 std vs raw 的 0.10）？
3. 区间宽度膨胀多少（cqr vs abs50 vs symabs）？
4. CRPS 恶化多少（相对 raw）？
5. 校准段 raw 覆盖率与测试段 raw 覆盖率的漂移——膨胀的根源？

## 执行后实证（2026-08-10 H100 全量 17 窗口 × 30 epoch，12.1 分钟）

**核心结论：均值已准（raw 就 0.8003 精确命中目标），但"稳定保证"没兑现——窗口间漂移是季节分布漂移，30d 校准段的共形修不了。**

1. **基线本来就准**：raw α=0.2 均值覆盖 0.8003（目标 0.80），B2/B7 的"碰运气"不是均值偏差而是窗口 std 0.090。
2. **cqr 在 α=0.2 几乎免费**：覆盖 0.8077、std 0.086（-5%）、宽 +2.0%、**CRPS 与 raw 完全持平**（0.8140 vs 0.8139）。逐视界 8 个全微改善。
3. **"稳定保证"没兑现**：逐窗口仍 0.66~0.94。corr(校准段 raw 覆盖, 测试段 raw 覆盖)=**0.339**——30d 校准段代表不了其后 90d 的季节波动。cqr 只在"校准段同样欠覆盖"的窗口生效（w10 +0.071、w1 +0.024），在"校准段正常/过覆盖但测试段漂移"的窗口（w5 0.662、w8 0.706、w9 0.699）完全无效——这些正是 raw 最需修复的窗口。
4. **对称共形变体更差**：abs50/symabs 把窗口 std 抬到 0.126（+40%），出现极端（abs50 w3 0.590/w4 0.573、w1 0.997；symabs w8 0.436）——对称绕 p50 丢弃偏度信息，对漂移更脆。
5. **α=0.1 够不着**：cqr 均值 0.851、仅 4/17 窗口 ≥0.90、宽 +26%。基线在 90% 层面本就欠校准。

**建议**：α=0.2 的 cqr 值得作为"理论保证层"（零成本、微改善、可对审稿人讲有限样本保证），但不解决窗口间漂移；α=0.1 不值（膨胀 26%）；对称变体不用。真正修复漂移需按季节分段校准/更大校准段——超出本次一次探索范围。
