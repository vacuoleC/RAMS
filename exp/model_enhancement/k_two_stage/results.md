# K 方向：两阶段训练（解"精度 vs 校准"矛盾）· 结果

> 探索标记：`exp/model_enhancement/k_two_stage/`（2026-08-10）
> 实验脚本：`run_k.py` ｜ 统计量：`results.json`（无原始数据行）｜ 日志：`run_full.log`
> 算力机：sensecore H100（torch 2.3.1+cu121），4 arm × 3 seed × 17 窗口，全量完成
> 协议：与 A 完全同口径（同一滚动窗口 730d/90d/步长 45d × 17，每窗口独立训练）；3 seed（0/1/2）
> 模型：**single** = GRU+分位数头（A 基准）｜ **multi** = RamsNet w=1/3/2（A 基准）｜ **ts_freeze** = Stage1 单任务 M1 20ep → Stage2 冻结 backbone 只训 M1/M2/M4 头 10ep ｜ **ts_full** = Stage1 单任务 M1 20ep → Stage2 解冻全部、多任务 loss 主导 10ep
> 输入：全剖面水温 + 气象 + 表层浓度 conc_t（27 特征）；目标 = Δ = conc_{t+h} − conc_t（增量口径，窗口训练段拟合 scale 防泄漏）
> 对照：持久化（Δ≡0 → conc_{t+h}=conc_t，逐视界一致）｜ 目标列：`conc_0.5`（表层）

## 结论（TL;DR）

**两阶段部分解开"精度 vs 校准"矛盾，且比"单任务"更进一步——不是二选一，而是两头都更好：`ts_freeze`（Stage1 单任务 + Stage2 冻结 backbone 微调多头）拿到全部 4 arm 中最优的点精度（CRPS 0.808 / RMSE 1.583，比单任务还低 5.7%），同时把覆盖率从单任务的 0.672 显著抬到 0.704（+3.2pp，16:1 胜）。但校准缺口未完全消除：覆盖率仍低于多任务 0.806、低于 80% 目标。**

1. **协议一致性逐位复现 A**：single（0.857/1.665/覆盖0.672，技能 +24.0%）与 multi（0.891/1.774/0.806，+21.0%）**逐位复现 A 的数字**；持久化 CRPS 均值 = 1.1281 = A/B7。四 arm 同测试段、可横向对照，本实验结论可信。
2. **假设方向成立（比预期更强）**：Stage1 单任务保住（甚至提升）精度 + Stage2 冻结 backbone 微调多头把校准往上抬。`ts_freeze` CRPS **0.808** < 单任务 0.857（**−5.7%**，逐窗口 16:1 胜，Wilcoxon **p=0.000**）< 多任务 0.891（**−9.3%**，p=0.011）；RMSE **1.583** < 单任务 1.665 < 多任务 1.774。**两阶段不仅在精度上不输单任务，反而超过了单任务。**
3. **但"完全解开"有边界**：`ts_freeze` 覆盖率 **0.704**——显著高于单任务 0.672（+3.2pp，p=0.000），但明显低于多任务 0.806、未达 80% 目标。**Stage1 把 backbone 的 p10/p90 带训窄了，Stage2 只训头 10ep 无法完全把带拉回 80%**；覆盖率对多任务缺 10.2pp（multi 16:1 胜，p=0.000）。
4. **冻结 vs 解冻是关键变量**：`ts_full`（解冻全部）两头都不占优——精度回到 ≈单任务（CRPS 0.868 vs 0.857，p=0.927 无差），校准只到 0.742（比 multi 0.806 低，p=0.001）。**解冻时 M2/M4 loss 主导把 p50 拖向多任务、p10/p90 也只部分打开 → 既没保住单任务的精度尖峰，也没拿到多任务的满校准。冻结 backbone 才是两阶段保存 Stage1 精度的必要条件。**
5. **辅助任务未被牺牲，M4 甚至更优**：ts_freeze M2=0.953 / M4=0.880（多任务 0.955/0.863）——M4 预警 acc 是 4 arm 最高。
6. **技能 vs 持久化**：ts_freeze **+28.4%** 全场最优（single +24.0%，multi +21.0%，ts_full +23.0%）。

## 关键问题回答

### Q 两阶段能否同时拿到单任务的精度 + 多任务的校准？

**能拿"最优精度 + 显著校准提升"，但校准未完全追平多任务。** `ts_freeze` 把矛盾从 A 的"二选一"变成了"精度最优（还比单任务更好）+ 校准从 0.672 抬到 0.704"：

- **精度侧：不仅保住，还反超。** ts_freeze CRPS 0.808 / RMSE 1.583，低于单任务（0.857/1.665）**且全部 8 视界、17 窗口中 16 个更优**。机制：Stage1 单任务把 M1 的 p50（点预测）训到单任务水准；Stage2 冻结 backbone 只训头——**p50 精度不被 M2/M4 梯度干扰**，同时额外 10ep 的 M1 分位数微调 + 头层多任务结构让 p10/p90 适度打开，CRPS（=点精度+区间质量）双赢。
- **校准侧：显著改善但仍欠。** 覆盖率 0.672 → 0.704（+3.2pp，p<0.001），但距 0.80 目标、距多任务 0.806 都还有 ~10pp 缺口。**根因：Stage1 已把 backbone 隐层对 Δ 的区间承诺训窄，Stage2 只训头 10ep 能打开的分位数带有限**——这是"精度优先起点"的固有代价。
- **冻结是必要条件**：ts_full（解冻）p50 被多任务 loss 拖回 ≈单任务（0.868 vs 0.857，无显著差），校准也只到 0.742。**只有冻结 backbone 才能保住 Stage1 的精度尖峰**。

### Q 生产建议（供主会话判断）

- **若要"M1 点精度优先 + 免费 M2/M4 + 校准比单任务好"**：**ts_freeze（20+10ep，冻结 backbone）是 4 arm 最优解**——CRPS/RMSE 全场最低、M2/M4 正常工作、覆盖率显著高于单任务。代价是覆盖率仍未达 80%。
- **若要覆盖达标 80%**：多任务（0.806）仍是唯一达标 arm；ts_freeze 需事后共形 / 更长 Stage2 / 更高 w_m2/w_m4 补校准。**下一步可探：ts_freeze 加长 Stage2（10→20ep）或 Stage2 只训 M1 的 p10/p90 头**能否把覆盖推到 0.75+。
- **ts_full 不建议**：两头不占优（精度 ≈ 单、校准 < 多），且多花 Stage1 的 20ep。
