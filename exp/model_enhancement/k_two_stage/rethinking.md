# K 方向：两阶段训练（解"精度 vs 校准"矛盾）· 思考记录（rethinking.md）

> 探索标记：`exp/model_enhancement/k_two_stage/`（2026-08-10）
> 实验脚本：`run_k.py` ｜ 结果：`results.md` / `results.json`（无原始数据行）
> 参考：`exp/model_enhancement/a_mt_increment/`（A 方向，17 窗口，两种 arm 都有）

## 任务意图

A 方向证实了"精度 vs 校准"的**未解矛盾**：
- **单任务增量**（GRU + 分位数头）：点精度好（CRPS **0.857** / RMSE **1.665**，全实验最优）但区间严重欠校准（覆盖率 **0.672**，目标 80%，不确定带偏窄）
- **多任务增量**（RamsNet w=1/3/2）：区间校准达标（覆盖率 **0.806**）但稀释点精度（CRPS 0.891 / RMSE 1.774，+3.9% / +6.6% 差）

**核心问题**：能否同时拿到单任务的精度 + 多任务的校准？两阶段训练可能解耦——
- **Stage1 单任务训 M1 增量**（保精度）：backbone + 头的表征完全朝 Δ 的点预测/分位数优化，不被辅助任务稀释
- **Stage2 多任务微调**（保校准）：冻结 backbone 只训多头（or 解冻但 M2/M4 loss 主导），辅助任务把不确定带校准回 80%

**关键设计决策**
1. **与 A 完全同口径**（同一 17 窗口协议、同一特征、同一增量目标、同一评估）：single/multi 两 arm 直接从 A 复现，作为对照基准。协议一致性靠 single/multi arm 复现 A 的数字来验证。
2. **两阶段 Stage1 用 RamsNet 只用 M1 loss**（不是 `IncrementQuantileNet`）：保证 Stage2 的 M2/M4 头存在，且只改"loss 构成"一个变量。Stage1 的 M1 loss / lr / batch / 打乱 / seed 与 train_single 完全一致。
3. **两个 Stage2 变体**（隔离"冻结"一个变量）：
   - `ts_freeze` = Stage1 20ep → Stage2 **冻结 backbone** 只训 M1/M2/M4 头 10ep
   - `ts_full`   = Stage1 20ep → Stage2 **解冻全部**，多任务 loss（w=1/3/2，M2+M4=5 > M1=1 主导）10ep
4. **3 seed（0/1/2）** 报告均值±std；Stage1 同一 seed 的重现性由本地 CPU/算力机同版本保证。
5. **评估**：每视界 CRPS/RMSE + 平均覆盖率（目标 80%）+ 辅助任务 acc（M2/M4 没被牺牲）+ vs 持久化技能。全部 conc 单位、同一测试段。
6. **M4 类别权重**：Stage2 按训练段自动逆频率（与冻结 `Trainer` 逻辑一致），保证 w=1/3/2 口径与 A 完全可比。

## 预期与反预期

- **若假设成立**：ts_freeze 覆盖 ≈ 0.80（校准达标）且 CRPS/RMSE ≈ 单任务（0.857/1.665）→ 同时拿到精度 + 校准，矛盾解开。
- **若 Stage2 干扰精度**：ts 的 CRPS/RMSE 回落到多任务水平（~0.89/1.77）→ 说明微调阶段必然破坏 Stage1 学到的精度，假设证伪。
- **若冻结不够**：ts_freeze 覆盖提升但 < 0.75（头权重太小、backbone 分位数带窄），ts_full 更接近 0.80 → "冻结 or 解冻"哪个变体能校准到 80% 本身也是答案。
- **反预期注意**：Stage2 只训 10ep、多任务 loss 可能推着 M1 的 p10/p90 向多任务带靠拢而 p50 保持单任务 → 可能出现"精度保持 + 校准恢复"的理想组合，也可能出现 p50 也被拖歪。

## 指标口径备忘

- 覆盖率：真实 conc ∈ [p10,p90] 比例（还原后），目标 80%。
- CRPS/RMSE 均在 conc 单位，四 arm 同尺度可直接比较。
- 相对技能 = (持久化 − 模型) / 持久化 × 100%，>0 = 模型更优。
- 多任务系 arm（multi/ts_freeze/ts_full）额外记录 M2/M4 测试 acc。
- 协议一致性：single/multi arm 应复现 A 的 0.857/0.891 等；持久化均值应 = 1.1281（A/B7 一致）。

## 执行后实证（2026-08-10 H100 全量 17 窗口 × 4 arm × 3 seed，~1.5h）

**核心结论：两阶段部分解开"精度 vs 校准"矛盾，且比"单任务"更进一步——不是二选一，而是两头都更好。`ts_freeze`（Stage1 单任务 M1 20ep → Stage2 冻结 backbone 只训多头 10ep）是 4 arm 最优点精度（CRPS 0.808 / RMSE 1.583），比单任务还低 5.7%，同时覆盖率显著抬到 0.704；但校准缺口未完全消除（仍低于多任务 0.806、未达 80%）。**

1. **协议一致性逐位复现 A**：single（0.857/1.665/0.672，+24.0%）与 multi（0.891/1.774/0.806，+21.0%）逐位复现 A；持久化 1.1281 = A/B7。四 arm 同测试段可横向对照。
2. **假设方向成立且更强**：ts_freeze CRPS 0.808 **低于**单任务 0.857（−5.7%，16:1 胜，Wilcoxon p=0.000）< 多任务 0.891（−9.3%，14:3，p=0.011）；RMSE 1.583 全场最低，全部 8 视界最优。**机制：Stage1 把 p50 点预测训到单任务水准；Stage2 冻结 backbone 只训头 → p50 不被 M2/M4 梯度干扰，额外 10ep 的 M1 分位数微调 + 头层多任务结构让 p10/p90 适度打开，CRPS（点精度+区间质量）双赢。**
3. **"完全解开"有边界**：ts_freeze 覆盖 0.704 显著高于单任务 0.672（+3.2pp，15:2，p=0.000），但比多任务 0.806 低 10.2pp、未达 80% 目标。**根因：Stage1 已把 backbone 隐层对 Δ 的区间承诺训窄，Stage2 只训头 10ep 能打开的分位数带有限——"精度优先起点"的固有代价。**
4. **冻结 vs 解冻是决定性变量**：ts_full（解冻全部）两头不占优——CRPS 0.868 ≈ 单任务 0.857（p=0.927 无显著差），校准仅 0.742 < 多任务 0.806（p=0.001）。**解冻时 M2/M4 loss 主导把 p50 拖向多任务、p10/p90 也只部分打开。冻结 backbone 才是两阶段保存 Stage1 精度的必要条件。**
5. **辅助任务未被牺牲，M4 更优**：ts_freeze M2=0.953 / M4=0.880（4 arm 最高；多任务 0.955/0.863）。
6. **技能 vs 持久化**：ts_freeze +28.4% 全场最优（single +24.0%，multi +21.0%，ts_full +23.0%）。

**建议**：M1 精度优先 + 免费 M2/M4 + 校准优于单任务 → **ts_freeze（20+10ep，冻结 backbone）**；覆盖达标 80% 仍需多任务，或 ts_freeze 加事后共形 / 更长 Stage2 / 更高 w_m2/w_m4 补校准；ts_full 不建议。下一步：Stage2 只训 p10/p90 头，或 Stage2 加长到 20ep。
