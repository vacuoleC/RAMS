# I 预测全剖面（表层 vs 全剖面 vs 关键层）· 思考记录（rethinking.md）

## 任务意图
目前所有模型（含正式模型方案）都只预测 `conc_0.5`（表层单层），但数据有 20 层完整剖面。
M3 已验证**输入侧**垂向信息价值（20 层输入降误差 32%）；本探索验证**输出侧**是否该用全剖面：
预测全剖面是**帮助表层**（多任务共享——分层结构让共享 backbone 学到更泛化的垂向表征，
辅助任务对主任务的正则/信息增益，类似 M2 分层任务 +8-15% 的机制）还是**拖累表层**
（M1 输出头负担变重、层间噪声干扰、梯度平均稀释表层信号）？

## 关键设计决策
1. **同一滚动窗口协议**（复用 B1/B2/B7/C：训练 730d / 测试 90d / 步长 45d，17 窗口），
   3 变体在**同一窗口集合、同一测试段**上对照，各自独立训练（3 seed [0,1,2]）。
2. **目标构造（abs_delta，B7 最优口径）**：按层定义 Δ_h(d) = conc_{t+h}(d) − conc_t(d)。
   各层独立计算、同一 scale 归一化（窗口训练段全部层目标值的 std，防泄漏；层间尺度假定可共享，
   因为 20 层浓度尺度同源，见数据检查）。
3. **变体定义**：
   - `surface`：M1 输出头只预测表层 conc_0.5（当前所有模型的做法，基线）
   - `full`：M1 输出头预测全剖面 20 层（同一共享 backbone）
   - `key`：M1 输出头预测关键层 {conc_0.5, conc_3.5, conc_7.0}（表层+中上层+中下层，3 层）
4. **架构**：冻结 `RamsNet` 只有单层 M1 头 → 在 exp/ 下扩展 `MLayerNet`（复用冻结组件
   SharedGRU/M1Head/M2Head/M4Head，仅 M1 输出维度扩到 3×NL×H，即同一 MLP 头出多层）。
   冻结 `Trainer/MultiTaskLoss` 的 M1 分位数损失只支持单层目标（reshape (-1,3,H) 无法广播到多层）
   → 在 run_i.py 内**复制冻结训练协议**（分位数损失 + M2/M4 交叉熵 + 同权重 w1/w2/w4 +
   Adam 1e-3 + batch 128 + 30 epoch + shuffle=False + M4 逆频率权重），仅把 M1 分位数损失
   泛化到多层（reshape(-1,NL,3,H)）。不触碰 rams/ 冻结代码。
5. **评估**（全部还原 conc 单位；CRPS 分位数闭合形式与 T4/B2/B7/C 一致）：
   - 表层（conc_0.5）逐视界 CRPS + p50 RMSE + 区间覆盖率 [p10,p90]——3 变体同一表层口径直接可比，
     回答"帮助还是拖累表层"
   - 全剖面重建 RMSE：full 变体各层 p50 还原后 vs 观测（表层/中层 5.0m/底层 10.0m + 全 20 层平均）
   - key 变体在所选 3 层各自重建 RMSE
   - 每变体各自"表层持久化"（零变化 = conc_{t+h}=conc_t）CRPS 作对照
6. **集成**：跨 seed 分位数平均（p10/p50/p90 各自平均）为每变体主答案（复用 C 结论）；
   同时记录单 seed 分布（seed CRPS 范围）。

## 指标口径备忘
- 表层 CRPS/RMSE/覆盖率：3 变体在同一 conc 单位直接可比。**核心对比是 surface vs full 的表层精度**。
- 重建 RMSE：full 变体 20 层 p50 还原后 vs 观测（conc 单位）。分层看表层/中层/底层。
- 持久化 CRPS：各变体内部"表层零变化"对照，算相对技能（>0 = 模型更优）。

## 预期与反预期
- 预期 A（多任务共享帮助表层）：full/key 的表层 CRPS/RMSE 不差于甚至优于 surface——垂向结构
  让 backbone 学到更泛化表征，表层信号被辅助层增强（类似 M2 高权重辅助的机制）。
- 预期 B（重建质量）：全剖面重建 RMSE 表层最低（信息最多、自回归最强）、中层/底层依次变差
  （更弱自回归、受垂向混合影响）。
- 反预期 A：若 full 表层 CRPS 明显差于 surface（>2% 任务阈值）→ 输出负担拖累表层，正式模型
  保持单层输出，全剖面另作重建任务（separate head / 两阶段：先表层后剖面）。
- 反预期 B：若 full 表层与 surface 打平但重建 RMSE 高（重建质量差）→ 全剖面输出"不帮助也不拖累
  表层"，但作为副产品重建价值存疑，需判断是否值得输出负担。
- 反预期 C：key（3 层）明显优于 full（20 层）→ 少量关键层足够提供共享增益，全剖面冗余。
