# A 方向：增量目标 × 完整多任务 · 结果

> 探索标记：`exp/model_enhancement/a_mt_increment/`（2026-08-10）
> 实验脚本：`run_a.py` ｜ 统计量：`results.json`（无原始数据行）｜ 日志：`run_full.log`
> 算力机：sensecore H100（torch 2.3.1+cu121），2 arm × 3 seed × 17 窗口 × 30 epoch，40.8 分钟
> 协议：同一滚动窗口（训练 730d / 测试 90d / 步长 45d，17 窗口），每窗口独立训练
> 模型：**单任务** = GRU 骨干 + 分位数头（`IncrementQuantileNet`，B1 同构）｜ **多任务** = RamsNet（M1 增量 + M2 分层 + M4 预警，w=1/3/2，= B7 abs_delta 完全同口径）
> 输入：全剖面水温 + 气象 + 表层浓度 conc_t（27 特征）；目标 = Δ = conc_{t+h} − conc_t（增量口径，窗口训练段拟合归一化 scale 防泄漏）
> 对照：持久化（Δ≡0 → conc_{t+h}=conc_t，逐视界一致）
> 目标列：`conc_0.5`（表层）

## 结论（TL;DR）

**多任务在增量基础上不再提升点预测精度（CRPS/RMSE），甚至轻微稀释；但把增量法的区间校准从严重欠覆盖拉回理想值。增量 × 多任务的叠加是"校准"而非"精度"。**

1. **协议一致性已证实**：本实验 17 窗口持久化 CRPS 均值 = 1.1281，与 B7 `crps_persist=1.1281` 逐位一致；且本实验多任务 arm（CRPS 0.891 / RMSE 1.774 / 覆盖 0.806）**逐项复现 B7 abs_delta**（0.895 / 1.789 / 0.794）——证明两个实验测试段完全相同、设置可横向对照。这是本实验可信度的基石。
2. **多任务不叠加点精度，反而轻微稀释**：单任务 CRPS 0.857 vs 多任务 0.891（多任务 +3.9% 差）；RMSE 1.665 vs 1.774（+6.6% 差）。但差值小、不显著（逐窗口 CRPS Wilcoxon p=0.24、RMSE p=0.33；逐窗口胜负 8:9 打平）。**与 T4"辅助任务稀释 M1"的观察一致，只是这里不显著。**
3. **多任务的真正贡献是区间校准**：覆盖率单任务 **0.672**（严重欠覆盖，目标 80%）→ 多任务 **0.806**（恰好达标，与 B7 0.794 一致）。**单任务增量把区间做窄了**（点精度好但不确定性低估）；多任务借辅助任务正则把不确定带校准回 80%。
4. **两条 arm 都持续化**（CRPS 技能 +24.0% / +21.0%），但增量在多任务下对 RMSE 的超越几乎消失（多任务 RMSE 技能 −0.2%，逐视界仅 h6/h7 微弱 +0.2~0.3%）。
5. **辅助任务未被牺牲**：多任务 arm M2 分层 acc=0.955、M4 预警 acc=0.863——M1 的轻微稀释换来的是 M2/M4 一起在工作。

## 关键问题回答

### Q1 多任务是否在增量基础上进一步提精度？
**点精度（CRPS/RMSE）不叠加，反而轻微稀释。** 单任务 CRPS 0.857 / RMSE 1.665 是全实验最优；多任务 CRPS 0.891（+3.9% 差）、RMSE 1.774（+6.6% 差）。虽然不显著（Wilcoxon p=0.24/0.33，逐窗口 9:8），但方向与 T4"辅助任务稀释 M1"一致——**增量目标把 M1 变得足够简单，辅助任务的梯度不再提供信息增益，反而摊薄了对 Δ 的拟合**。

### Q2 会不会稀释 M1？—— 轻微稀释（点精度），但换来区间校准
是轻微稀释：多任务点预测（CRPS/RMSE）系统性比单任务差 ~4~6%。**但**覆盖率从 0.672 → 0.806（目标 80%）：单任务增量的区间严重欠覆盖（不确定带偏窄），多任务通过共享 backbone 的正则把不确定带校准回理想水平。辅助任务 M2（0.955）/M4（0.863）保持高质量，没有被牺牲。

### Q3 两条已验证的线是否叠加？—— 叠加的是"校准"，不是"精度"
- **若"叠加"定义为精度（CRPS/RMSE）再提升：不叠加**，甚至轻微负叠加（不显著）。
- **若"叠加"定义为整体多任务收益：部分叠加**——多任务修复了单任务增量的欠覆盖短板，同时保住 M2/M4 能力，使增量法从"点准、区间窄"变为"点准、区间准、附送 M2/M4"。
- **代价**：RMSE 对持久化的优势几乎消失（多任务 +6.0% → −0.2%），CRPS 技能也从 +24% → +21%。

### Q4 与 B1/B7 的关系
B1（单任务增量 28-fold）与 B7（多任务增量 17 窗口）协议不同，**此前无法直接比较**。本实验在同一协议下消除混淆：**单任务增量（0.857）其实优于多任务增量（0.891）**——B1 单任务拿到的 CRPS 优势有一部分确实来自"没有辅助任务稀释"，而非协议差异。但 B7 的 abs_delta 覆盖 0.794 vs B1 的区间质量（未报告覆盖）——多任务校准优势在 B7 里就在，本实验用配对对照把它量化了。

## 建议采纳方向（供主会话判断）
- **若目标是单任务 M1 点预测精度**：单任务增量（`IncrementQuantileNet`）CRPS/RMSE 最优，但区间欠覆盖（0.67）需配合额外校准（如 B2 分位数调优 / C4 递归不用 / 共形）。
- **若目标是生产系统（要 M1 准 + 区间可信 + M2/M4 一起工作）**：多任务增量（w=1/3/2）是平衡解——点精度只损失 ~4%，换区间校准达标（0.81）+ M2/M4 免费。**正式模型建议保留多任务增量，与 B7 建议一致。**
- **增量 × 多任务的"叠加"本质**：不是点精度的乘法，而是"精度+校准+多任务"的整合。若要再压点精度，下一步可探多任务权重（降 w_m2/w_m4）或增量 + 单任务 + 事后共形。
