# A 方向：增量目标 × 完整多任务 · 思考记录（rethinking.md）

> 探索标记：`exp/model_enhancement/a_mt_increment/`（2026-08-10）
> 实验脚本：`run_a.py` ｜ 结果：`results.md` / `results.json`（无原始数据行）

## 任务意图

两条已验证的线从未在同一协议下组合测过：
1. **增量目标**（B1/B2/B7）：Δ = conc_{t+h} − conc_t 让模型全视界超越持久化（RMSE −2~4.8%, CRPS −28~37%）。但 B1 是**单任务** GRU（28-fold 协议），B7 的 abs_delta 虽是**多任务**（w=1/3/2，17 窗口协议），却从未与"增量 × 单任务"在同一协议下直接对照。
2. **多任务架构**（框架比较）：多任务本身贡献巨大（单任务 GRU 5.89 → 多任务 3.64，绝对浓度口径，差 2.25）。

**核心问题**：增量目标 × 完整多任务（M1 增量 + M2 分层 + M4 预警）是否**叠加**？还是会像 T4 见过的那样被辅助任务**稀释 M1**？

## 关键设计决策

1. **严格隔离两个变量**：同一滚动窗口协议（训练 730d / 测试 90d / 步长 45d，17 窗口，与 B2/B7 完全一致），同一测试段、同一特征（temp_* + 气象 + conc_t）、同一增量目标口径（归一化用窗口训练段拟合 scale 防泄漏）。唯一变量 = 任务架构：
   - **单任务** = GRU 骨干 + 分位数头（p10/p50/p90，与 B1 完全同构的 `IncrementQuantileNet`）
   - **多任务** = 冻结 `RamsNet`（use_m4=True，M1 增量 + M2 分层 + M4 预警，w=1/3/2，= B7 abs_delta 完全同口径）
2. **3 seed（0/1/2）报告均值±std**：每窗口每 seed 独立训练（防单 seed 偶然）。
3. **评估全部还原 conc 单位**，同一测试段：
   - 每视界 CRPS（分位数闭合形式，与 T4/B2/B7 一致实现）
   - 每视界 p50 RMSE
   - 平均 CRPS / RMSE / 覆盖率（p10-p90 命中）
   - vs 持久化（Δ≡0 → conc_{t+h}=conc_t）相对技能
4. **协议一致性校验（关键）**：窗口内切分用 `n_tr = int(n_win × 730/820)`（n_win = 820 天样本数），与 B7 `build_window` 一致。校验：本实验 17 窗口持久化 MAE 均值 = **1.1281**，与 B7 `crps_persist=1.1281` **逐位一致**——证明测试段采样与 B7 完全相同，两实验可直接横向对比。
5. **单任务训练的对照口径**：训练用随机打乱 + lr=1e-3 + batch=128 + 30 epoch（与 B1 的 `train_increment` 一致）；多任务用冻结 `Trainer`（batch=128，M4 类别权重自动逆频率）。两者都是各自协议下"最标准"配置。

## 指标口径备忘

- 覆盖率：真实 conc ∈ [p10,p90] 比例（还原后），目标 80%。
- CRPS/RMSE 均在 conc 单位，两个 arm 可直接比较（同一尺度、同一测试段）。
- 相对技能 = (持久化 − 模型) / 持久化 × 100%，>0 = 模型更优。
- 多任务 arm 额外记录 M2/M4 辅助任务测试 acc（验证辅助任务没被"牺牲"）。

## 预期与反预期

- **若叠加**：多任务 CRPS/RMSE 应显著优于单任务（增量基础上再降），且全视界一致。
- **若稀释**：多任务 CRPS/RMSE 劣于单任务（辅助 loss 干扰 M1 增量学习），或仅中间视界持平。
- **持平**：多任务贡献已被增量目标"吸收"（增量让 M1 太简单，辅助任务不再提供梯度信息增益）。
- 反预期注意：B1 单任务是 28-fold 协议、B7 多任务是 17 窗口协议——**两者数字不可直接跨表比较**，本实验的意义正是在同一协议下消除这个混淆。

## 执行后实证（2026-08-10 H100 全量 17 窗口 × 2 arm × 3 seed × 30 epoch，40.8 分钟）

**核心结论：多任务在增量基础上不叠加点精度（轻微稀释），但把区间校准从欠覆盖拉回理想值——增量 × 多任务的"叠加"是校准而非精度。**

1. **协议一致性证实**：17 窗口持久化 CRPS 均值 = 1.1281 = B7 `crps_persist`；本实验多任务 arm（CRPS 0.891 / RMSE 1.774 / 覆盖 0.806）**逐项复现 B7 abs_delta**（0.895 / 1.789 / 0.794）。两实验同测试段、可横向对照。
2. **点精度不叠加、轻微稀释（应验 T4 稀释预期）**：单任务 CRPS 0.857 / RMSE 1.665（全实验最优）vs 多任务 0.891 / 1.774（+3.9% / +6.6% 差）。不显著（逐窗口 Wilcoxon p=0.24/0.33，胜负 9:8 打平），但方向与 T4"辅助任务稀释 M1"一致——**增量把 M1 变简单后，辅助任务梯度不再提供信息增益，反而摊薄 Δ 拟合**。
3. **多任务真正贡献 = 区间校准**：覆盖率 0.672（单任务严重欠覆盖，不确定带偏窄）→ 0.806（多任务恰好达标 80%，与 B7 0.794 一致）。共享 backbone 的辅助任务正则把不确定带校准回理想。
4. **RMSE 对持久化优势在多任务下消失**：单任务 +6.0% → 多任务 −0.2%；CRPS 技能 +24% → +21%。两 arm 仍都超持久化（增量线成立）。
5. **辅助任务未被牺牲**：多任务 M2 acc=0.955、M4 acc=0.863。

**建议**：生产系统保留多任务增量（w=1/3/2）——点精度只损失 ~4%，换区间校准达标 + M2/M4 免费；纯 M1 点精度优先则单任务增量 + 额外校准（共形/分位数调优）。下一步可探降 w_m2/w_m4 是否压回点精度。
