# O_multilayer_link · 事件记录（whatwedo.md）

- **时间**：2026-08-10
- **方向**：O 多层信号之间的联系
- **标记**：`exp/model_enhancement/o_multilayer_link/` 已建立
- **核心发现**：
  1. **同步性（A）**：浓度 0-5m 内近冗余（相邻层相关 0.971、表层带组内 0.951），5.5-10m 与表层解耦（表层 vs 10m 0.148、跨组表层×底层 0.188）。**暴发期解耦更强**：2021 表层-10m 相关 -0.07 vs 非暴发 0.57 —— 这是 M5/I/E"深层无用"的机制证据。
  2. **相位滞后（B）被证伪**：30 天去季节残差 + 日平均剔除昼夜伪影后，跨层互相关峰全部在 h=0，无"深层领先表层"；3h 尺度的整数天峰是昼夜周期混叠伪影（表层 24h 功率 16%）。事件锚定（N 的 12 事件）深层领先仅 20-36%，逐事件高度异质 → 垂向迁移非普遍机制。
  3. **变率谱（C）修正直觉**：全柱主导周期 ~400 天季节；表层最快（2-7d 功率 0.06、24h 0.16）；**深层 8-10m 不是慢而是"快而弱"**（自相关 efold 最短 17-19 天）；真正最持久的是中层 1-3.5m（efold ≥60 天）。
  4. 水温与浓度结构完全不同：全柱高度同步（表层 vs 10m 0.87，组内>0.99），是热分层渐变场，无深层独立维度；水温呈表层先变的轻微下行传热方向。
- **方法学发现**：3h 采样的跨层滞后相关必须先日平均/滤波排除昼夜周期混叠，否则"整数天滞后峰"会误判为真实相位。
