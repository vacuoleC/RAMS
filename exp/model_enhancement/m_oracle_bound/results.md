# M 方向：oracle 信息上限探针 · 结果

> 探索标记：`exp/model_enhancement/m_oracle_bound/`（2026-08-10）
> 实验脚本：`run_m.py`（掩蔽已知段损失版）｜ 统计量：`results.json`（无原始数据行）
> 算力机：sensecore H100（torch 2.3.1+cu121），6 arm × 3 seed × 17 窗口 × 30 epoch，31.8 分钟
> 协议：同一滚动窗口（训练 730d / 测试 90d / 步长 45d，17 窗口），每窗口独立训练
> 模型：base/ar_only = RamsNet（GRU + p10/p50/p90 + M2/M4 多任务 w=1/3/2，与 A/B7 一致）
>       oracle 臂 = OracleRamsNet（通道 + 头注入 + 已知段损失掩蔽）
> 目标：`conc_0.5`（表层）增量 abs_delta。数据含 242 零值（log1p 安全处理与 A/B7 一致）

## 为什么用 H=64（8 天）探针视界
若探针用 H=8（1 天，与公开基线同协议），oracle N≥1 天就完整覆盖目标窗 → 所有 oracle 档
CRPS≈0，退化无信息。H=64 让 oracle 只覆盖前 N 天，后 8−N 天是"诚实"预报区；N=1/3/7 有
可区分读数，且能测"轨迹信息随视界的衰减"。代价是 H=64 共享骨干稀释短视界精度
（window1 实测 base8 H=8 CRPS 2.44 vs base64 第1天 3.13），但所有 oracle 臂同 H=64 对称可比，
绝对锚定由 base8 臂提供（见下，精确复现 A 方向）。

## 协议一致性验证（锚定可信）
**base8 精确复现 A 方向 multi arm**：CRPS 0.8912 / 持久化 1.1281 / 相对技能 +21.0%，
与 `a_mt_increment/results.json` 逐位一致。探针臂与公开基线同协议可比，结论可外推到当前模型。

## 世界观判定（TL;DR）

**World A/C——我们已接近数据的信息上限。oracle 给足 1~7 天真实未来轨迹，也无法把 1 天前
预报 CRPS 降到当前模型（0.95）以下。** 数据可预测信息基本被当前增量模型提取完毕，
继续榨模型收益递减。**纯自回归（仅 conc 历史）就达到最优（0.87），temp/气象特征是噪声。**

三条独立证据（互洽）：

1. **1 天前预报的 oracle 阶梯（同难度，关键数字）**：已知 0 天 0.949 → 已知 1 天 1.132
   → 已知 3 天 1.111 → 已知 7 天 1.115。**多知道真实轨迹不降低 1 天前 CRPS（反而略升）**
   ——"用昨天之前的轨迹预测明天"的可提取信号已被当前模型提取完。
2. **纯自回归已达最优**：ar_only（仅 conc 历史）第 1 天 0.872，**优于**全特征 base 0.949
   （temp/气象反而 −8.8%）；全 8 天 CRPS_all 1.280 vs 1.381（−7.3%）。与 E/D/J/M5 一致：
   "水温→藻类"直接/间接路径都不成立，增量信号全在藻类自回归。
3. **长视界（4-8 天）oracle 有"提升"但不可桥接**：固定目标日对比，base 第4天 1.402 → 已知
   3 天 1.111（+20.8%）、第8天 1.643 → 已知 7 天 1.115（+32.1%）。**这是"距离效应"**
   （知道中间轨迹 = 离目标日更近），推理时不可能有 → 不可桥接的固有代价（任务原话：
   "未来7天未知的固有噪声"）。不是历史可提取信号，无部署价值。

## 关键对照（两种口径，避免误读）

### A. 1 天前预报阶梯（同难度：都是从最后已知点预报其后 1 天）
| 已知轨迹 | 读数来源 | CRPS | vs 已知0天 |
|---|---|---|---|
| 0 天 | base 第1天 | **0.949** | — |
| 1 天 | oracle_1 第2天 | 1.132 | −19.3% |
| 3 天 | oracle_3 第4天 | 1.111 | −17.1% |
| 7 天 | oracle_7 第8天 | 1.115 | −17.5% |

**多知道 1~7 天真实轨迹，1 天前预报反而略差（−17~−19%），绝无提升。**
"预测明天"的可提取信号已被当前模型提取完。

### B. 固定目标日（控制目标日，oracle 移除距离）
| 目标日 | base（N 天前） | oracle（已知轨迹后1天前） | 提升 |
|---|---|---|---|
| 第2天 | 1.162 | 1.132（已知1天） | +2.5% |
| 第4天 | 1.402 | 1.111（已知3天） | +20.8% |
| 第8天 | 1.643 | 1.115（已知7天） | +32.1% |

**误读风险**：看似 oracle 大幅提升，实为"知道中间轨迹 = 离目标日更近"（1 天前 vs 8 天前）。
推理时未来不可知 → 这是不可桥接的固有代价，不是可提取信号。**正确读数看 A。**

## 特征贡献（非自回归信号量）

| 口径 | ar_only（仅conc） | base（全特征） | 差 |
|---|---|---|---|
| 第1天 CRPS | **0.872** | 0.949 | temp/气象 −8.8% |
| 8天 CRPS_all | **1.2802** | 1.3813 | −7.3% |

**纯自回归（仅 conc 历史）反而最优**：当前特征集（全剖面水温 + 气象 + conc）相对纯自回归
是负贡献。与 E（分层趋势无预测力）、D（wind 无益）、J（慢变量伤精度）、M5（气象直接驱动弱）
**四线互洽**：藻类 24h 增量的信号几乎全在自回归历史，当前模型的短板不是"缺特征"，而是
数据本身在 1 天前预报上的信息就这么多。

## World C 检验（暴发期是否有被评估掩盖的空间）

逐窗口 gap = base 第1天 CRPS − oracle_7 第8天 CRPS（1 天前 vs 已知7天后1天前，同难度）：

- **corr(gap, 浓度范围) = +0.750**，corr(gap, 浓度std) = +0.775
- 方向符合 World C 预期：高波动（暴发）窗口 gap 更大（oracle 相对更有效）
- **但绝对幅度极小**：最大窗口（w1，conc_range=24.5，暴发）gap=+0.265（base 2.998 → oracle 2.732，
  仅 +8.8%）；其余 16 个窗口 gap 全部为负（base 反而更好）
- **结论**：暴发窗口略有"已知轨迹后预报"的空间，但远低于世界观 B 需要的 >50%，
  且这部分仍含距离效应。**World C 只有微弱、非实质性的支持。**

## 世界观结论（用数据说话）

**World A/C：接近信息上限。** 当前增量模型（CRPS≈0.89~0.95）已提取了数据在当前特征集下
1 天前预报的可预测信息的大部分：

- oracle 给足 7 天真实未来轨迹，**1 天前预报 CRPS 无法降到 0.95 以下**（反而 1.11，模型更优）
- 纯自回归已达最优（0.87），temp/气象是噪声——**没有"非自回归信号"可挖**
- 长视界（4-8 天）的 oracle "提升"是未来不可知的固有代价，**不可桥接、不可部署**

**可预测上限 ≈ 当前水平，继续榨模型收益递减**。这与 J（方向 AUC 0.59 是数据上限）、E/D/M5
（物理链不成立）互相印证：**单站藻类数据的增量可预测性由自回归过程噪声决定，方法已接近该边界。**

## 建议（供主会话判断）

1. **正式模型定稿增量 abs_delta + 多任务**（当前方案），不必继续追点精度——数据上限已到。
2. **若要再压误差**，方向是**数据/评估协议**（多站合并、更长观测期、CRPS 滚动窗口已定稿），
   而非继续调模型结构/特征（特征已证伪为噪声）。
3. **预警系统定位**：1 天前预报已接近过程噪声底，预警应聚焦"当前浓度水平的风险分级"
   （M4 直接分级）而非"预测未来的暴涨/暴跌"（后者受限于数据上限）。
4. 若未来有**更高频/更丰富驱动数据**（降雨、入流、垂向混合实测），oracle 探针应重跑：
   新的可预测上限会显现（当前上限受自回归过程噪声支配）。
