# D: wind_u 交叉特征在增量目标下重测 · 思考记录（rethinking.md）

## 任务意图
T1 在**绝对浓度**目标下测过 wind_u：边际有效（20 层上降 2.1%，5 层上反而增 +4.2%）。
M5（PCMCI+）证明 wind_u 短滞（≤2 天）是唯一有信号的气象直驱：wind_u→cyano τ=1 r=+0.072、
wind_u→temp_surf τ=2 r=+0.125。

**关键洞察**：绝对浓度目标里，藻类强自回归（τ=1 r≈+0.63）主导预测，气象信号被淹没。
B1/B2/B7 已证明**增量目标**（Δ=conc_{t+h}-conc_t）去掉自回归主导后，模型是在预测"偏离"而非"水平"——
此时"风大时浓度如何偏离"的弱信号可能浮现。

本实验在增量 abs_delta 口径下重测 wind_u，验证其是否比 T1 绝对口径（-2.1%）更有用。

## 关键设计决策
1. **协议完全复用 B7 的增量 abs_delta 基线**：同一滚动窗口（训练 730d / 测试 90d / 步长 45d，17 窗口），
   同一 RamsNet 分位数模型（GRU 骨干 + p10/p50/p90 + M2/M4 多任务），同一目标构造/还原/评估。
   这样本实验的 base 可直接与 B7 的 abs_delta 交叉核对。
2. **特征变体**（唯一差异 = 特征通道，其余完全一致）：
   - `base`：现输入 = 全剖面水温 temp_*（20）+ 气象 METEO_COLS（6）+ conc_t（1）= 27 通道（B7 基线）
   - `wind_u`：base + wind_u 短滞通道（28 通道）
   - `cross`：base + wind_u×conc_t 交叉通道（28 通道）
   - `both`：base + wind_u + cross（29 通道，bonus：若单加任一个有效，两者叠加是否更强）
3. **wind_u 计算**（与 T1/M5 完全一致）：`wind_u = wind_speed * cos(deg2rad(wind_dir))`。
   风向是环形量，先转 u 分量避免对角度取均值。
4. **交叉特征形式**：`wind_u × conc_0.5` **每时刻**通道。T=24（3 天）回看窗口天然覆盖
   wind_u 的 0~2 天短滞效应，GRU 能学到"前 1-2 天风大 + 当前浓度高 → 未来偏离"的滞后结构，
   不需要手工构造滞后的 cross（handcrafted lag 会锁死 M5 的 τ=1/2，GRU 可自适应）。
5. **3 seed**：每窗口每变体独立训练 3 次（seed 0/1/2），报告均值±std（约束要求）。
   与 T1（3-seed）对齐，避免单 seed 偶然性。
6. **归一化**：全部特征通道（含 wind_u、cross）用训练段统计量标准化，防泄漏。

## 指标口径（复用 B7）
- 目标：Δ = conc_{t+h} - conc_t（原始浓度尺度），窗口训练段 std 归一化；评估还原 conc 单位。
- CRPS：p10/p50/p90 分位数闭合解，还原 conc 单位，**与 B7 一致**。
- RMSE：p50 还原 conc 单位。
- 对照：各自持久化（Δ=0 → conc_{t+h}=conc_t）。
- 核心比较：**wind_u 变体 vs base 的 ΔCRPS / ΔRMSE**，以及 wind_u 变体的"相对持久化技能"是否比
  B7 abs_delta（+20.6%）更高。

## 预期与反预期
- 若 wind_u 在增量下 CRPS/RMSE 比 base 降 >1.5% → 假设成立（wind_u 在增量口径比绝对口径 -2.1% 更有用）。
- 若 wind_u 增量下表现 ≈ base（差 <1%）→ 弱信号（r≈0.07）被 GRU 冗余吸收（M5 结论：风是
  温度驱动的"果"非"因"，信息已藏在 temp_* 里），wind_u 无独立增量价值。
- cross 若有效而纯 wind_u 无效 → "风 × 浓度水平"是信号载体（交互效应），非 wind_u 单独。
- 反预期：cross 数值尺度大（高浓度段大），可能放大低浓度噪声 → 需看窗口间方差与低浓度段。
