# D: wind_u 交叉特征在增量目标下重测 · 结果

> 探索标记：`exp/model_enhancement/d_wind_cross/`（2026-08-10）
> 实验脚本：`run_d.py` ｜ 统计量：`results.json`（无原始数据行）｜ 思考：`rethinking.md`
> 算力机：sensecore H100（torch 2.3.1+cu121），4 变体 × 3 seed × 17 窗口 × 30 epoch，93.4 分钟
> 协议：增量 abs_delta（Δ=conc_{t+h}−conc_t），训练 730d / 测试 90d / 步长 45d，17 窗口
> 模型：RamsNet（GRU + p10/p50/p90 + M2/M4 多任务）；每窗口每变体独立训练 3 seed
> 目标：`conc_0.5`（表层）。wind_u = wind_speed×cos(deg2rad(wind_dir))（与 T1/M5 一致）

## 背景问题

T1 在**绝对浓度**目标下测过 wind_u：20 层上边际降 2.1%（3-seed）。M5（PCMCI+）证明
wind_u 短滞（≤2 天）是唯一有信号的气象直驱（wind_u→cyano τ=1 r=+0.072、wind_u→temp_surf τ=2
r=+0.125）。本实验检验假设：**绝对浓度里自相关占主导、气象被淹没；增量目标去掉自相关后，
wind_u 的"风大时浓度如何偏离"信号可能浮现，比 T1 绝对口径更有用。**

## 4 特征变体（唯一差异 = 特征通道，其余完全一致）

| 变体 | 特征通道 | feat_dim | 说明 |
|---|---|---|---|
| **base** | 现输入 = 全剖面水温 20 + 气象 6 + conc_t 1 | 27 | B7 abs_delta 基线 |
| **wind_u** | base + wind_u 短滞通道 | 28 | wind_u = wind_speed×cos(deg2rad(wind_dir)) |
| **cross** | base + wind_u×conc_0.5 交叉通道 | 28 | 每时刻交叉，T=24 覆盖 0~3 天短滞 |
| **both** | base + wind_u + cross | 29 | 叠加（bonus） |

## 结论（TL;DR）

**wind_u 在增量目标下无益——三个变体全部比 base 略差。假设被证伪。**

1. **三个 wind 变体全部微劣于 base**：wind_u CRPS **+1.24%** / cross **+0.75%** / both **+0.89%**；
   RMSE 全部 **+1.1~1.2%**；覆盖率略降（base 0.806 → 0.793-0.800）。差异均 <1.3%，且方向不一致
   （wind_u 8/17 窗口赢、cross 7/17、both 9/17），**无稳定信号**。
2. **与 T1 绝对口径对比：增量没有解锁 wind_u 信号，反而更差**。T1 绝对目标下 wind_u 20 层边际
   降 2.1%（微弱有效）；增量目标下 wind_u 反而 +1.24%。**"去掉自相关后气象信号浮现"的假设不成立。**
3. **增量口径下 base 已是最优**：base CRPS 0.8912 / RMSE 1.774 / 覆盖 0.806 / 相对持久化技能
   +21.0%，与 B7 abs_delta（0.895 / 1.789 / 0.794 / +20.6%）几乎一致，确认协议可复现。
4. **交叉特征（cross）不比纯 wind_u 强**：cross 全视界 CRPS 平均略优于 wind_u（+0.75% vs
   +1.24%），但窗口间仍 7/17 赢、无一致性，且 12 号窗口劣化达 11.9%（交叉放大高浓度窗口噪声）。

## 与 T1 绝对口径的对照

| 口径 | wind_u 变体效果（vs 各自基线） |
|---|---|
| T1 绝对浓度（20 层 + 气象，3-seed） | RMSE **−2.1%**（边际有效） |
| 本实验增量 abs_delta（27 特征 + 3-seed） | CRPS **+1.24%**、RMSE **+1.17%**（微劣） |

**结论：wind_u 在增量目标下不是更有用，而是更没用。** 假设（"去掉自相关后气象弱信号浮现"）
被数据否定。可能解释：

1. **增量目标下模型已经在学"偏离"，但 wind_u 不携带额外信息**。base 已含全剖面水温 temp_*（20 层）
   与风速/风向。M5 的 PCMCI 结论——wind_u→temp_surf 是温度驱动的果，不是独立的因——在增量口径
   同样成立：wind_u 的信息已冗余在 temp_* 序列里，加通道只增加参数量/噪声（+1.2% 正是"加 1 个
   弱噪声通道"的典型代价）。
2. **增量目标改变了"偏离"的定义**：Δ=conc_{t+h}−conc_t 在短期内由自相关惯性主导（t 到 t+1 的 Δ
   依然强相关），wind_u 的 0~2 天作用早已被 Δ 的短期结构吸收，加 wind_u 无增量收益。
3. T1 绝对口径的 −2.1% 是**绝对水平预测**下 GRU 借 wind_u 微调浓度水平（如风大时均值略降），
   在增量口径这个"水平校正"被 conc_t 直接提供（base 已有 conc_t 通道），wind_u 变得多余。

## 关键问题回答

### Q1 wind_u 在增量目标下是否有用？
**没有。** 三个 wind 变体（纯 wind_u / wind_u×conc 交叉 / 叠加）全部微劣于 base（CRPS
+0.75~+1.24%，RMSE +1.1~1.2%），且逐窗口赢面 7-9/17 无一致性。增量目标没有解锁 wind_u 信号。

### Q2 交叉特征（wind_u×conc）是否比纯 wind_u 更有用？
**微弱、不稳定。** cross 平均 CRPS 劣化（+0.75%）小于 wind_u（+1.24%），且两者赢窗口几乎互补
（wind_u 赢 w1,2,6,7；cross 赢 w11,13,14,16），但 cross 同样只有 7/17 窗口赢，12 号窗口劣化
11.9%。没有证据支持"交互效应是信号载体"。

### Q3 与 T1 绝对口径的结论是否一致？
**方向相反**：T1 绝对口径 wind_u 边际降 2.1%（微弱有效）；增量口径 wind_u 反而 +1.24%（微劣）。
这强化了既有边界决策——**不建议给 M1 单独加 wind_u 通道**（架构蓝图 §3.7 结论在增量口径下
更加成立）。

## 建议采纳方向（供主会话判断）

- **正式模型维持 base（27 特征，现输入 + conc_t）**：增量口径下 wind_u / cross / both 均无增益，
  加通道反而略损（+0.8~1.2%）。此探索为"wind_u 不建议单独加通道"提供了增量口径下的实证。
- **不继续 wind 交叉方向**：若想再压 M1 精度，气象方向应转向其它更可能带独立信息的气象量
  （如日照/辐射——目前 METEO_COLS 不含，可能是真正的独立驱动），而非 wind_u 的再加工。
- **T1 的 −2.1% 不构成增量口径的采纳依据**：该增益是"绝对水平预测"下的水平校正，已被 base 的
  conc_t 通道覆盖。
