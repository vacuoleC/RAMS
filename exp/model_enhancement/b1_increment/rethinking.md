# B1 增量预测 · 思考记录（rethinking）

**任务背景**：藻类浓度强自回归（M5：τ=1 自相关 r=+0.63），持久化猜中水平 80%；现有模型直接预测绝对浓度 RMSE 不敌持久化。假设：模型预测变化量 Δ = conc_{t+h} - conc_t 而非绝对值，持久化即 Δ=0，模型学会修正即赢。

## 思考过程

1. **问题重构**：把"猜中水平"与"修正水平"解耦。水平信息完全由输入特征 conc_t 携带，模型只需要学"在水平 x 的基础上，未来 h 步会怎么变"。这天然契合分位数回归（Δ 的分位数平移回浓度坐标即可）。

2. **管线细节决策**：
   - 目标 Δ 用原始浓度尺度（不归一化）→ 分位数损失无尺度扭曲，预测浓度 = conc_t + Δ 直接在原始坐标。
   - conc_t 拼进特征（强先验），20 层水温 + 6 气象共 27 维。
   - 滚动窗口必须"窗口整体落段"，防止训练窗口末时刻跨越测试边界造成泄漏；归一化与气候学月均值只从训练段拟合。

3. **踩过的坑**（已修复，留档）：
   - Δ 张量列偏移：目标行写错成 i+T+h-1 但 h 从 0 起 → 首列全 0、末列缺 Δ_H。修复：列 j → 行 i+T+j。
   - CRPS 初版公式符号混乱 → 改用分位积分表示 CRPS = 2/K Σ_j ρ_a(y-q_j)，并验证点预测退化精确等于 MAE。

4. **结果解读**：
   - 增量模型全视界超持久化（RMSE -2%~-4.8%，CRPS -28%~-37%），3 seed 稳定。
   - 绝对模型 h=1/7/8 输给持久化——正是增量模型改善最大的两端，机制吻合：短视界持久化太强（Δ≈0），长视界绝对模型回归到均值、丢掉自回归。
   - 气候学（季节均值）远差（RMSE≈6.2），说明逐次事件（藻华）不可由季节拟合，必须靠自回归状态。

## 未来方向

- 增量 + 分层特征 / M5 气象滞后变量，压 h4~6 峰值 RMSE。
- 20 层浓度多目标增量（当前仅表层 0.5m）。
- 增量目标与绝对目标混合（multi-task），或 conc_t 通道做 attention。
