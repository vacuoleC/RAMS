# C4 探索：递归预测 vs 直接多步（强自相关序列）

> 目录：`exp/model_enhancement/c4_recursive/`

> - 全量 17 窗口 × 3 seed × 30 epoch = 29.9 分钟（**本报告数字为 3-seed 均值**）

## 1. 做了什么

对强自相关序列（M5 实证表层浓度 τ=1 自相关 r≈+0.63）比较两种多步预测策略：

| 策略 | 实现 |
|---|---|
| **直接多步**（现状） | GRU 读 T=24 输入 → M1 头一步输出 H=8 未来（p10/p50/p90 分位数） |
| **递归**（假设更适配） | GRU 读 T=24 → 头输出 1 步 → 把 p50 喂回浓度通道、外生通道置 0 → GRUCell 更新隐状态 → 循环 8 次 |

**公平口径**（唯一差异 = 预测策略）：
- 特征通道 D=27 = 20 层水温 + 6 气象 + 表层浓度（递归要"喂回预测"，两边都必须见历史浓度）
- 结构一致：GRU(hidden=64) + M1 分位数头，分位数损失；去掉 M2/M4 辅助任务隔离变量
- 递归训练用 scheduled sampling（teacher forcing 0.9→0.1 线性衰减），评估纯递归（暴露误差累积）
- 评估：滚动窗口（训练 730 天 / 测试 90 天 / 每 45 天推进，共 17 窗口），逐视界 RMSE（还原原始 µg/L）+ CRPS（p10/p50/p90 闭合解）
- 对照：持久化（最后观测浓度）、气候学（训练段同月均值）

> 记录过的 bug：递归 teacher forcing 初版误用 `y[:, hh]`（用当前目标喂输入预测同一步 → 短路），修为 `y[:, hh-1]` 后递归验证 loss 正常收敛（见 trydoing.jsonl）。

## 3. 递归是否更适合强自相关数据？

**前半场是，后半场不是。** 3-seed 结果与 1-seed 高度一致，结论稳健。关键结论：

1. **短视界（h=1~4，未来 3-12h）递归更好**：h4 递归 RMSE 3.44 vs 直接 4.73（**−27.3%**），CRPS 2.98 vs 3.61（−17.4%）；h1 递归也占优（−6.0%）。h2/h3 基本打平。递归每步用"最新预测浓度"喂回，短期自相关强，该信息价值高。
2. **长视界（h=5~8，未来 15-24h）递归急剧劣化**：h8 递归 RMSE 10.85 vs 直接 4.36（**+148.8%**）。这是**误差累积**的直接证据——每步把上一步的误差当输入放大。
3. **误差累积可量化**：从 h1 到 h8，RMSE 增量直接多步仅 +2.54，递归高达 +9.14（3.6 倍）。递归的 RMSE 曲线近似**指数发散**（1.71→10.85），直接多步基本平稳（1.5~5.3 波动）。
4. **对强自相关序列的机制解读**：自相关强 → 递归短视界能吃到"最近值"，直接多步却把所有视界"一起出"浪费了中间观测。但自相关在 H=8（24h）时已衰减到接近消失（M5 证实短滞主导），递归累积的噪声远超其保留的自相关信号 → 长视界崩盘。

**综合判断**：递归**不是**对强自相关序列的普适更优解。它在"自相关仍显著的视界"（≤12h）占优，在"自相关衰减后的视界"（>12h）因误差累积崩盘。若想兼顾两端，可考虑**多步"热身 + 递归收尾"的混合策略**（前几步 teacher 预热、后面递归展开），或对递归加误差抑制（如预测 delta 而非水平值、衰减记忆）。

## 4. 结论（含误差累积观察）

- **R1｜递归 vs 直接：谁更好，取决于视界**。h≤4 递归平均 RMSE 2.17 vs 直接 2.51（**−14%**），CRPS 1.70 vs 1.85；h≥5 直接平均 RMSE 4.59 vs 递归 8.16（直接 −44% 于递归）。**无绝对赢家**，赢家是视界的函数。
- **R2｜递归长视界无优势**：原假设"递归在长视界靠逐步累积最新信息更有优势"被**证伪**——长视界反而是直接多步更强（h8 直接 4.36 远低于递归 10.85）。递归的"最新信息"在 24h 尺度上已不新鲜，且被误差累积淹没。
- **R3｜误差累积是递归的硬伤**：h8 递归 RMSE 10.85（超出多数窗口训练段 std，与直接差距 6.5 µg/L）。scheduled sampling 只能缓解训练-推断不一致，不能消除递归展开本身的噪声放大。**递归适合"视界短 + 自相关强"的问题**（如 3-12h 藻类短期趋势），不适合本任务 24h 固定视界。
- **R4｜持久化仍最硬**：全视界持久化 RMSE 1.34~1.98 低于两个模型（与 T2/T4 结论一致——该序列近"局部恒定"，24h 内波动远小于模型误差）。模型（尤其是递归长视界）还没好到能超持久化；直接多步在 h2 与持久化最接近。
- **R5｜工程建议**：若采纳递归，方向应是**混合策略**或**缩短递归展开**（如 T=24 只递归 4 步到 12h，剩余用直接或持久化），而不是全递归 8 步。
