# J 中长程慢变量特征 · 思考记录（rethinking.md）

## 任务意图
当前输入是 T=24（3 天）窗口 + conc_t，**只有短期记忆**。M5 已证实藻类 ACF 衰减需 75-90 天
（强季节性/长记忆）。短板识别：特征缺"中长程季节状态"——这可能同时是
- 短板 2（方向判别弱）：B_direction 实证 AUC≈0.59、sign-acc 0.539，弱但真实；若模型知道
  "当前处于上升季还是下降季"（季节相位），P(Δ>0) 判别可能更强；
- 短板 1（区间校准漂移）：H 实证窗口 std 0.09，漂移核心是"年际状态漂移"；慢变量显式编码
  "当前状态"（均值水平/趋势/方差），模型不确定性可能跟状态走，降窗口间 std。

J 假设：给增量模型（abs_delta，A/B7 最优口径）加慢变量特征（过去 30/60/90 天的均值/趋势/
方差，只对 conc_0.5 与 air_temp 计算），可能同时帮方向判别和区间校准，也可能只是叠加噪音。

## 关键设计决策
1. **同一滚动窗口协议**（复用 A/B/C/B7/H：训练 730d / 测试 90d / 步长 45d，17 窗口），
   2 变体 × 3 seed（0/1/2），每窗口独立训练同一 RamsNet（GRU 骨干 + p10/p50/p90 +
   M2/M4 多任务，w=1/3/2，与 B7/A 完全一致）。base 与 slow 只在特征维度不同（F=27 vs 42），
   其余完全隔离，可精确对照。
2. **慢变量定义**：对 conc_0.5 与 air_temp 各算 W∈{30,60,90} 天的滚动 mean / slope /
   (conc 另加 std)。conc 是目标自身的长程状态（均值水平、上升/下降趋势、波动幅度）；
   air_temp 是 M5 里唯一有微弱直接作用的气象（温度→藻类季节性），其长程均值编码季节相位。
   共 15 个慢变量通道。
3. **防泄漏（关键）**：
   - 只用 [t−W, t) 的**过去**值：shift(1) 后 rolling，因果，当前时刻 t 的 conc 不参与；
   - 慢变量在窗口**训练段**拟合均值/方差标准化（与既有特征一致），再应用到全窗口；
   - 评估段慢变量取值只依赖窗口起点（含 90d 预热缓冲）之前的信息；
   - 头部预热期 NaN：ffill 用更早历史，剩余头部块用首个有效值常数扩展（只落在第 1 窗口
     训练段内，且不引入逐行未来信息）。
4. **方向评估口径**（与 B_direction 完全一致）：P(Δ>0)=Φ(q50/σ_gauss)，σ_gauss=(q90−q10)/2.563，
   ROC-AUC（阈值无关，诚实）+ p50 符号命中率（B7 口径对照）。方向标签 up = Δ>0 vs cur_t。
5. **慢变量诊断**：先算慢变量与 conc_t / Δconc 的相关（全数据集聚合），看慢变量是否
   携带 Δ 的线性信号——若 corr≈0，预判模型级收益也不会大（但仍需模型级确认，
   因为季节状态的判别是"条件性"的，非线性相关）。
6. **对照目标**：base 应复现 A/B7 的 abs_delta 多任务（CRPS≈0.89-0.90、RMSE≈1.77-1.79、
   覆盖≈0.79-0.81、方向 AUC≈0.59）。若 base 与已知值偏差大，先排查协议 bug 再跑慢变量。

## 指标口径备忘
- CRPS / p50RMSE：全部还原 conc 单位，同一测试段；与持久化（Δ≡0）比相对技能。
- 覆盖 [p10,p90]：目标 80%，**重点看窗口间 std**（短板 1：H 基线 std≈0.09）。
- 方向 AUC：P(Δ>0)=Φ(q50/σ) 逐视界 ROC-AUC，seed×窗口 展平均值；与 B_direction 的 0.59 对照。

## 预期与反预期
- 预期（假设成立）：slow 在方向 AUC 上升（0.59 → +），或覆盖窗口 std 下降，或 CRPS 降。
- 反预期 1（最可能）：慢变量与 Δ 的相关本来就弱（M5：藻类自回归主导、气象直接驱动弱），
  slow 只是叠加冗余/噪音通道 → CRPS/RMSE/方向/覆盖全部打平或微劣（类似 E 方向负结果）。
- 反预期 2：slow 提升 CRPS/校准但方向 AUC 不动 → 慢变量帮的是"区间"短板而非"方向"。
- 反预期 3：slow 的方向 AUC 提升但过拟合训练段季节 → 测试段不泛化，窗口 std 反而升。
- 收敛判据：若全部指标 Δ 在噪声级（|ΔCRPS|<1%、|ΔAUC|<0.01），诚实判定"不值得加"，
  与 D/E 方向（wind、分层趋势均负结果）一致：**增量信号主要由藻类自回归携带**。

## 执行后实证（2026-08-10 H100 全量 17 窗口 × 2 变体 × 3 seed × 30 epoch，25.7 分钟）

**核心结论：慢变量"方向判别显著变差 + 点精度微劣 + 覆盖 std 降 6.5%"，假设只部分成立
（只帮短板1的窗口std），不成立的部分（短板2 方向、点精度）占比更大，不值得整体加入。**

1. **协议复现确认**：base arm 逐项复现 A 多任务（CRPS 0.8912 / RMSE 1.7745 / 覆盖 0.8063 /
   持久化 1.1281），方向 AUC 0.581 ≈ B_direction 0.591 → 慢变量差异是真实的。
2. **方向判别（短板2）显著变差（反预期）**：AUC 0.581 → 0.564（-0.016，p=0.006 显著），
   17 窗口里 14 个变差。慢变量编码的"季节相位"对 24h Δ 方向无判别力（与 Δ 相关 ≤0.037），
   反而是冗余通道稀释了短程自回归的方向信号。**方向判别弱不是"缺季节状态"造成的。**
3. **区间校准（短板1）部分改善**：覆盖 0.806→0.815（p=0.43 不显著）、窗口 std 0.0875→0.0818
   （-6.5%），H 的漂移窗口 4/5 改善（w10 +0.079）。但这是"救回失守窗口 + 恶化正常窗口"的
   混合（w2/w4/w5/w11 反而 -0.04~-0.09），11/17 覆盖胜率不干净。机制：慢变量水平通道
   corr(conc_t)>0.7 → 让不确定性与季节水平相关，正好补 H 的"年际状态脱钩"。
4. **点精度微劣**：CRPS +1.71%（p=0.109）、RMSE +2.25%（p=0.023 显著），w12 +24.9% / w14
   +12.1% 两个大失败窗口决定性。
5. **与 E/D 方向呼应**：慢变量与 Δ 的线性相关全部 |r|≤0.037（分层趋势 corr≈0 同理），
   再次确认**增量信号主要由藻类短程自回归携带，季节/长程状态对未来 24h 变化几乎无预测力**。

**建议**：正式模型不加慢变量通道。方向判别（短板2）的结论固化——B_direction 的 AUC≈0.59
是数据上限，方向信号在短程自回归里，长程状态喂不进去；校准稳定性线索保留（"把年际状态喂给
不确定性估计"作为独立校准层可行，如 H 的 seas_reg 用慢变量替代月因子），但不应塞进 M1 输入。
