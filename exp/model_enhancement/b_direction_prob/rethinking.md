# B_direction_prob · 思考记录（rethinking.md）

## 任务意图
B2/B7 两轮探索都暴露：增量分位数模型 p50 的**方向判别弱**（sign 命中率 0.53≈随机，平凡基线 0.49-0.51）。B7 排除"目标尺度"因素后，方向判别弱是 **Δ 本身接近不可判别**（P(Δ>0)≈0.49 且随窗口漂移 0.40-0.55，无稳定可分特征）。建议另配 **P(Δ>0) 概率输出 + 阈值校准**。

本实验直接检验这个建议：
- Q1 P(Δ>0) 是否比 p50 符号更有判别力？（ROC-AUC / 方向命中率 / Brier）
- Q2 概率校准是否可靠？（校准曲线 P(Δ>0) 预测 vs 实际频率，ECE / Brier）
- Q3 方向是否**本质上不可判别**？（若全部方法 AUC≈0.5 且校准可靠 → 数据限制而非方法缺陷）

## 关键设计决策
1. **窗口协议**：同 B7 的 820d 窗口 / 步长 45d，但窗口内切 640d 训练 / 90d 校准 / 90d 测试——**校准段（阈值扫 τ、Isotonic 拟合）与测试段分离防泄漏**。测试段与 B7 完全一致（窗口最后 90d），数字可直接对照 B7。
2. **方向概率 4 来源**：
   - `p50_sign`：B7 基线（非概率，sign(q50_delta)）
   - `gauss`：Φ(q50/σ)，σ=(q90-q10)/2.563（分位数反推高斯）
   - `pchip` / `linear`：单调三次/线性分段 CDF 插值求 F(0)（分位数反推，非对称）
   - `binary`：GRU 骨干上加**方向头**（B,H 二元 logits，BCE 与 M1/M2/M4 联合训练）
3. **理论备忘（关键）**：凡 P 是 q50 的**单调函数**（gauss/pchip/linear 都满足）：
   - **acc@0.5 与 p50 符号恒等**（P(g)=g(0)=0.5 时，"P>0.5" 与 "q50>0" 一一对应）；
   - **ROC-AUC 与 q50 连续分值的 AUC 恒等**（单调变换保序，AUC 只看排序）；
   - 关键推论：**连续分值的 AUC（≈0.59）会显著高于符号 acc@0.5（≈0.54）**——0.5 截断丢弃了 q50 离 0 的幅度信息。B2/B7 用 sign-acc 衡量方向，**低估了真实判别力**。
   - 因此分位数反推法的判别力上限 = q50 连续分值；**只有直接训练的二分类头可能超越 q50 学到额外判别信息**——这是本实验真正要检验的（binary vs gauss 的 AUC 差）。
4. **评估指标**：
   - 方向命中率：acc@0.5（B7 口径）、acc@τ_cal（校准段最优阈值）、acc@iso（Isotonic 校准后）
   - ROC-AUC（阈值无关的诚实判别指标）
   - Brier score（原始 + Isotonic 校准后）
   - ECE（10 bin 校准曲线）+ 校准曲线 bin 表（P 预测 vs 实际频率）
   - 平凡基线：常量预测器 max(up_rate, 1-up_rate)
5. **模型**：B7 同架构（GRU 骨干 + M1 p10/p50/p90 分位数头 + M2 分层 + M4 预警），新增方向头（M1Head 结构复用，输出 B×H logits）。多任务权重 M1/M2/M4 与 B7 相同（1/3/2），方向头权重 1.0。abs_delta 目标（B7 建议正式模型保留的口径）。
6. **标签处理**：up = Δ>0；Δ=0 记作"不上"（占比 ~1.3%，影响可忽略，已在设计说明）。测试段每视界 up_rate 单独算常量基线，避免类不平衡抬高 acc 假象。
7. **3 seed（0/1/2）× 17 窗口**：与 B7/C4 同协议，seed 差异纳入窗口均值。

## 预期与反预期
- 若 binary 头 AUC 显著 > q50 连续 AUC（gauss 基线）→ 专用方向头学到 q50 之外的额外判别信息，方向预警可行。
- 若 binary 头 AUC ≈ gauss AUC → 判别信息已编码在分位数输出里，不值得加专用头。
- 若全部方法 AUC ≈ 0.5 且校准可靠（ECE 小）→ **方向本质上不可判别**，结论=数据限制。
- 实测：全部方法 AUC≈0.59（非 0.5），binary≈gauss → **弱判别 + 判别信息已在分位数里**。
- 反预期可能：binary 头因多任务共享骨干可能过拟合方向（训练段 Δ 可判别、测试段不泛化）——用测试段 AUC 与校准段/测试段差来识别。
- 反预期 2：分位数反推的 gauss/pchip 在 q50≈0 附近会退化到 0.5（不确定区间覆盖 0），Brier 天然接近 0.25——这不是"判别力"，而是"校准到均匀"。

## 数据特性备忘
- conc_0.5（表层）含 242 个零值，Δ=conc_{t+h}-conc_t 零值约 1.3%，h 近端多。
- 测试段 up_rate 漂移（B7 报告 0.40-0.55 窗口间漂移）——常量基线随窗口变，acc 口径需同时看。

## 执行记录（增量更新）

### 2026-08-10 · 全量实证（H100，17 窗口 × 3 seed × 30 epoch，36.9 分钟）

**核心结论：P(Δ>0) 有弱判别力（AUC≈0.59），不是"完全不可判别"；但作为硬分类（yes/no 方向预警）不可用。**

1. **模型 sanity 通过**：M1 覆盖率 0.795 / CRPS 0.905（B7=0.794/0.895）——加方向头不损伤回归任务，且单位还原 bug 修复验证有效。
2. **P(Δ>0) 判别力（阈值无关 AUC）**：gauss 0.591 / linear 0.593 / pchip 0.592 / binary 0.594，窗口 std≈0.03，**全部方法显著 >0.5**。p50 符号 acc@0.5 只有 0.539（常量基线 0.528，仅 +1.1pp）——**连续概率的排序信息比"符号在 0.5 处截断"更强**（AUC 0.59 vs sign-acc 0.539 的差异 = 概率幅度的价值）。
3. **关键反预期：二分类头不增加判别力**。binary AUC 0.594 vs gauss 0.591（+0.003），binary acc@0.5 0.548 vs p50_sign 0.539（+0.9pp）——**直接训练的专用方向头相对"分位数反推 P"几乎无增益**。判别信息已经编码在 q50（及区间宽度）里。
4. **阈值校准无收益**：最优 τ 全部 ≈0.50-0.51（up_rate≈0.49 平衡且分布近对称），acc@τ_cal≈acc@0.5。Isotonic 反而**恶化** Brier（0.25→0.267）与 ECE——原始概率在中间段已较平，校准段小样本外推到尾部过拟合。
5. **Brier 无技能（校准曲线扁平）**：所有方法 Brier≈0.250 ≈ 常量基线 0.2499（技能 -0.2%~-2%）。概率预测集中在 0.4-0.6，平方误差上不优于气候率。
6. **校准曲线单调但欠锐利**：mid 段压缩（binary pred 0.45→obs 0.48、pred 0.55→obs 0.52），高置信尾有真实提升（binary pred 0.74→obs 0.63、pred 0.83→obs 0.74，相对 base 0.49 提升 1.3-1.5x；gauss pred 0.93→obs 0.71）。存在系统性高置信过自信（gauss 0.93→0.71）。

**结论（诚实）**：
- B2/B7 的"方向判别弱（0.53≈随机）"是用 **sign-acc@0.5** 衡量的——它低估了连续 q50 的排序判别力（AUC 0.59）。方向**不是完全不可判别**，而是**弱且集中在高置信尾**。
- 但 P(Δ>0) **作为硬 yes/no 分类不可用**：sign-acc 仅 0.539、Brier 无技能、校准曲线扁。**可用作软信号**（置信加权的方向提示，只在 P>0.7 时提示"可能上升"）。
- **建议**：方向预警用"分位数反推 P(Δ>0)（gauss 即可）+ 高置信阈值（P>0.7）+ 软提示"组合，**不值得加专用二分类头**（+0.003 AUC）、**不值得做阈值/Isotonic 校准**（无收益或负收益）。
