# E 分层状态趋势喂增量 · 结果

> 探索标记：`exp/model_enhancement/e_strat_trend/`（2026-08-10）
> 实验脚本：`corr_precheck.py`（相关性快速验证）+ `run_e.py`（模型级确认）
> 统计量：`corr_precheck.json` / `results.json`（无原始数据行）
> 算力机：sensecore H100（torch 2.3.1+cu121），2 变体 × 17 窗口 × 3 seed × 30 epoch，64.3 分钟
> 协议：同一滚动窗口（训练 730d / 测试 90d / 步长 45d，17 窗口），每窗口每 seed 独立训练
> 模型：RamsNet（GRU 骨干 + p10/p50/p90 分位数头 + M2/M4 多任务，与 B7 完全一致）
> 目标：`conc_0.5`（表层）abs_delta 增量口径，全 conc 单位评估

## 假设与设计

M5 证水温对藻类**无因果中介**（temp→conc 无 MCI 显著边）。本方向检验补充物理链
"分层状态变化 → 垂向混合 → 藻类分布变化"是否在**增量 Δ** 上浮现：
把分层状态（delta_T / thermo_grad）的**趋势**（3 天 = 8 时刻窗口的变化，非当前值）
作为特征喂增量预测。

| 变体 | 输入 | 说明 |
|---|---|---|
| **base**（基线） | temp_* + 气象 + conc_t | B7/B1/B2 增量基线，27 特征 |
| **trend**（变体） | base + 分层趋势 3 维 | `trend_dT`（delta_T 3 天差分）+ `slope_dT`（3 天线性斜率）+ `d_thermo_grad`（thermo_grad 3 天差分） |

两变体统一使用裁剪冷启动段（前 8 时刻）后的宽表，时间轴/窗口/测试段完全一致；特征标准化只用窗口训练段。

## 相关性预检（先做，任务要求）

对全数据 12607 时刻 + 17 窗口训练段，corr(分层趋势特征, Δconc_h)，h ∈ {1,3,8}：

| 特征 | Pearson | Spearman | Bootstrap95CI(Pearson, 3 seed) |
|---|---|---|---|
| trend_dT（delta_T 3 天差分） | −0.047 ~ +0.026 | +0.030 ~ +0.053 | 几乎全含 0 |
| slope_dT（delta_T 3 天斜率） | −0.077 ~ +0.025 | −0.051 ~ +0.066 | 几乎全含 0 |
| d_thermo_grad（温跃层梯度 3 天差分） | +0.023 ~ +0.120 | +0.022 ~ +0.038 | 几乎全含 0 |

**分层趋势对 Δconc 无线性预测力**：全部 |r| ≤ 0.12，绝大多数 < 0.08。

补充诊断（排除"查错对象"质疑）：
- **季节混淆控制**：对月份去均值后 d_thermo_grad h=8 仍 +0.12 → 非季节共变；但 Spearman 仅 +0.04 → 该微弱信号是**重尾极值驱动**（Pearson 对极值敏感）。
- **多滞后检查**（趋势在 t−τ，τ=0/3/7/14/28 天 vs Δconc h8）：全部 |r|≤0.11，无滞后错位解释。
- **分组可解释方差**：按 trend_dT 正负分组的 Δconc(h8) 均值差 |Δmean|/std(Δconc)=**0.016** → 分层趋势方向分组解释的方差≈0。
- **level vs trend 对照**：分层状态**当前值** LEVEL dT pear −0.017、LEVEL thermo pear +0.146，也不比趋势强——物理链在 level 与 trend 两种口径下都不成立。

## 关键问题回答

### Q1 分层趋势是否对增量有预测力？
**没有。** 两道证据一致：
1. **相关性预检**：corr(Δconc, 分层趋势特征) 全部 |r| ≤ 0.12（绝大多数 < 0.08），Bootstrap95CI 几乎全含 0；按 trend_dT 正负分组的 Δconc 均值差 |Δmean|/std(Δconc)=0.016（解释方差≈0）。
2. **模型级确认**：加分层趋势后 CRPS Δ=−0.2%、RMSE Δ=−1.0%，幅度低于噪声尺度；区间覆盖反而更差（0.804→0.792）。神经网络在相关≈0 的输入上无法凭空造出预测信号，且 +3 维输入略增过拟合。

### Q2 分层趋势特征是否有用？
**无用。** 不采纳为正式模型特征。唯一的微弱亮点（p50 RMSE 在 h3-6 −1.5%）伴随覆盖退化，且方向不跨视界一致，属过拟合噪声而非真实信号。

### Q3 那 +0.12 的 d_thermo_grad 信号怎么回事？
**重尾极值 + 无滞后结构，非真实信号。** h=8 视界 Pearson +0.12 但 Spearman 仅 +0.038；去季节后不变（非季节共变）；多滞后检查（趋势在 t−τ，τ=0/3/7/14/28 天）全部 |r|≤0.11——若分层趋势真驱动 Δconc 应有时间滞后结构，但没有任何滞后浮现。Pearson 对少数极端事件敏感，这是相关幻觉而非因果信号。

## 与 M5 中介结论的对话

本 E 方向的结论**与 M5 的中介结论互相印证、构成互补证据**：

1. **M5（因果图层面）**：水温对藻类**无因果中介**——temp→conc 无 MCI 显著边。PCMCI+ 在控制藻类自回归后，水温（含分层）的**直接因果路径**不显著。
2. **本 E（增量特征层面）**：分层状态的**趋势**（3 天差分/斜率）与藻类**增量 Δ** 的线性相关≈0（|r|≤0.12），喂给增量模型后 CRPS/RMSE 无增益（Δ≤1%）。即使把物理链放宽到"分层状态变化 → 垂向混合 → 藻类分布变化"的**变化驱动**口径，数据上仍不成立。

两条证据链合起来：**"水温→藻类"的直接路径（M5）与"分层趋势→Δ"的间接路径（本 E）在单站 SITE_X 数据上都不成立。** 藻类增量的可预测信号主要由**藻类自回归**携带（M5: τ=1 自相关 r≈+0.63；B1/B2/B7 增量模型相对持久化 +20% 技能）。分层/水温是弱外围信号，且在本站数据的观测尺度上不构成可学习的预测信息。

**对本项目含义**：不要指望给模型加分层趋势特征来提升增量预测——没有预测力。若要做"分层驱动藻类分布"的真实科研结论，需要**多站/同化剖面数据**（垂向混合发生在亚网格尺度，单站 3h 离散采样观测不到其时间结构），或**物理模型耦合**（把混合动力学作为先验注入），纯统计特征扩展在此数据上行不通。

## 建议采纳方向

- **不采纳**分层趋势特征进正式模型：相关性预检 + 模型级确认双证无预测力。
- 藻类增量预测**保持现状**（abs_delta 增量口径，B7 结论）：自回归是主导信号。
- 若后续想探索"垂向混合"物理链，应换**多站/亚网格数据**或**物理耦合**，而非在本站数据上加统计特征。
