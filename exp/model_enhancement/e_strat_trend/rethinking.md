# E 分层状态趋势喂增量 · 思考记录（rethinking.md）

## 任务意图
M5 证水温对藻类**无因果中介**（temp→conc 无 MCI 显著边），"水温→藻类"直接路径不利。
但物理链"分层状态变化 → 垂向混合 → 藻类分布变化"可能在**增量 Δ** 上浮现：
把分层状态（delta_T / thermo_grad）的**趋势**（3 天内的差分/斜率，而非当前值）作为特征
喂增量预测，可能对 Δ 有预测力。

## 关键设计决策
1. **先快速验证，再决定是否硬做**（任务明确要求）：先做 corr(Δconc, Δstratification)，
   若接近 0 直接诚实报告"物理链在数据上不成立"。
2. **分层趋势特征定义**（3 天 = 8 时刻窗口，与 B7 的 T=24 同尺度）：
   - `trend_dT` = delta_T[t] − delta_T[t−8]（表层−底层温差 3 天差分，"分层强度变化"）
   - `slope_dT` = delta_T 在 3 天窗口内对时刻索引的线性斜率（对端点噪声鲁棒）
   - `d_thermo_grad` = thermo_grad[t] − thermo_grad[t−8]（温跃层最大梯度 3 天差分）
3. **评估协议**：与 B7 完全一致的 abs_delta 增量协议（训练 730d / 测试 90d / 步长 45d，
   17 窗口），每窗口独立训练 RamsNet（GRU + p10/p50/p90 + M2/M4 多任务）。
   对照：base（现输入：temp_* + 气象 + conc_t）vs trend（base + 3 维分层趋势）。
   3-seed（seed 0/1/2）跨窗口×seed 聚合。
4. **公平性**：两变体统一使用裁剪冷启动段（前 LAG 时刻）后的宽表，时间轴、窗口、测试段
   完全一致；特征标准化只用窗口训练段（防泄漏）。

## 相关性预检（2026-08-10，本地 CPU 全数据）
对 12607 时刻全数据 + 17 窗口训练段，计算 corr(分层趋势特征, Δconc_h)，h ∈ {1,3,8}：

| 特征 | Pearson 范围 | Spearman 范围 | Bootstrap95CI(Pearson) |
|---|---|---|---|
| trend_dT | −0.047 ~ +0.026 | +0.030 ~ +0.053 | 几乎全含 0 |
| slope_dT | −0.077 ~ +0.025 | −0.051 ~ +0.066 | 几乎全含 0 |
| d_thermo_grad | +0.023 ~ +0.120 | +0.022 ~ +0.038 | 几乎全含 0 |

**结论：分层趋势对 Δconc 无线性预测力。** 全部 |r| ≤ 0.12，绝大多数 < 0.08。

补充诊断（排除"我查错了对象"的质疑）：
- **季节混淆控制**：对月份去均值后 d_thermo_grad h=8 的 Pearson 仍 +0.12 → 非季节共变混淆，
  但 Spearman 只有 +0.04 → 该信号是**重尾极值驱动**（Pearson 对极值敏感），秩相关几乎为 0。
- **多滞后检查**：趋势在 t−τ（τ=0,3,7,14,28 天）vs Δconc(h8)：全部 |r|≤0.11，无滞后错位解释。
- **分组可解释方差**：按 trend_dT 正负分组的 Δconc(h8) 均值差 |Δmean|/std(Δconc)=0.016——
  分层趋势方向分组解释的方差几乎为 0。
- **对照（当前值 level vs 趋势 trend）**：LEVEL delta_T pear −0.017、LEVEL thermo pear +0.146，
  当前值也不比趋势更强；物理链在 level 与 trend 两种口径下都不成立。

## 预期与反预期
- 若相关性≈0，诚实报告"物理链在数据上不成立"——M5 的中介结论**得到增量层面的补充确认**：
  分层状态趋势变化不携带 Δconc 的线性信息，垂向混合→藻类分布变化的物理链在本站数据（单站
  0902，表层 conc_0.5 目标）上不可观测为统计信号。
- 反预期（应验的）：d_thermo_grad 在 h=8 出现 Pearson +0.12，看似有微弱信号——但 Spearman
  0.038 与多滞后检查证明是重尾极值 + 无滞后结构，非真实可预测信号。
- 即便线性相关≈0，非线性/多元模式仍可能超出线性相关——故仍跑模型级对照（H100）作最终确认。

## 模型级确认（H100，3-seed，64.3 分钟）

即便线性相关≈0，仍跑模型对照（非线性/多元模式可能超出线性相关）作最终确认。
17 窗口 × 2 变体 × 3 seed × 30 epoch，结果（conc 单位，跨窗口×seed 均值）：

| 指标 | base | trend | Δ(trend−base) |
|---|---|---|---|
| CRPS | 0.883 | 0.881 | −0.002（−0.23%） |
| p50 RMSE | 1.728 | 1.711 | −0.017（−1.00%） |
| 覆盖率 | 0.804 | 0.792 | −0.012 |
| 覆盖窗口 std | 0.078 | 0.096 | +0.018 |

**结论：加分层趋势特征在模型级几乎无影响——CRPS Δ=−0.2%、RMSE Δ=−1.0%，幅度低于窗口噪声尺度（RMSE 窗口 std ≈ 0.3-0.5）；区间覆盖反而更差（0.804→0.792，窗口 std 更差）。** trend 在 11/17 窗口 CRPS 略优但符号混杂（w1/w10/w15 明显更差），无窗口类型规律。神经网络在相关≈0 的输入上无法凭空造出预测信号，+3 维输入略增过拟合（覆盖退化是其代价）。

## 边界决策

**边界决策通过（负结果）**：本方向结论 = **分层趋势喂增量无预测力**。与 M5 中介结论对话："水温→藻类"直接路径（M5 无 MCI 边）+ "分层趋势→Δ"间接路径（本 E）**两条物理链在数据上都不成立**。藻类增量可预测信号主要由**自回归**携带（M5: τ=1 r≈+0.63）。不采纳分层趋势特征。若要探索"垂向混合→藻类分布"，需多站/亚网格数据或物理模型耦合，本站单点 3h 采样观测不到该物理链的时间结构。
