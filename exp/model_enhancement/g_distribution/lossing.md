# G 完整分布输出（IQN / 分位数网格）· 边界决策记录（lossing.md）

## 该探索对原方案（M1 分位数输出）的理解与边界
- 原方案 = 冻结 RamsNet：GRU 骨干 + M1 分位数头（p10/p50/p90）+ M2/M4 多任务。本探索**只替换 M1 头的输出形式**，共享骨干与 M2/M4 完全复用（不触碰 rams/ 冻结代码，仅 import）。
- IQN/q9 若显著更优（CRPS 相对技能提升 ≥2% 且校准不退化），是**对 M1 头的增量替换**，符合原方向"提升预测/预警精度"的意图，不偏离。
- 若 IQN 收益 <2%，结论是**维持 3 分位数**——完整分布输出带来的复杂度（IQN 训练不稳定、预测需采样重建 CDF、PIT 评估额外负担）不抵消其精度收益。

## 理解偏差风险
1. **CRPS 口径偏差**：iqn 用能量形式（精确）、base3/q9 用分段线性闭合形式（近似）。若直接把两者数值对比会高估 iqn 收益——分段线性近似在结之间是线性插值，能量形式对经验 CDF 精确，两者都**低估**真实 CRPS（离散化）。但 q9（9 结分段线性）与 iqn（64 点能量）在同一目标分布上收敛到同一真实 CRPS（合成验证：1.1408 vs 1.1418，差 0.1%），所以数值可比。
2. **训练口径偏差**：base3 走 run_b7 冻结 Trainer（w1=1/w2=3/w4=2），q9/iqn 走 run_g 自写训练循环（同一权重）。若训练配置有出入，会污染对比。已核对：损失组成与权重一致；唯一差异是 iqn 的 pinball 是 K=32 τ 平均（base3 是固定 3 分位）。
3. **持久化口径**：3 变体同一 abs_delta 口径，持久化 CRPS 相同，直接比模型 CRPS 无偏。

## 效果偏差 / 可能的损失
- 若 iqn 优于 base3：损失是"采用 IQN 后架构更复杂（+cos 嵌入头、+采样），且 IQN 训练方差更大（随机 τ）"。若收益 <2%，此复杂度损失不必要。
- 若 iqn 优于 base3 但 q9 ≈ iqn：损失是"为收益引入 IQN 的连续 τ 采样"其实不必要——9 个固定分位数头（更简单、更稳）能拿到同样收益。采纳建议应指向 q9 而非 IQN。
- 若 iqn 差于 base3：损失为零（结论是维持现状）。但需排除"训练不收敛"假阴性——30 epoch 对 IQN 可能不足，需在 rethinking 记录该不确定性。

## 损失的必要性
- 探索的"必须损失"：为回答"完整分布 vs 3 分位数 CRPS 提升多少、值得改架构吗"，必须承担 3 变体 × 3 seed 的训练成本与 IQN 训练的额外噪声。这是回答该开放问题的必要成本。
- 无数据泄露：所有统计量聚合输出，results.json 无原始数据行。

## 判定
- 边界**与原方向相符**：替换 M1 输出形式属于"模型架构增量优化"，与总方向（预测/预警精度 + 不确定量化）一致。
- 待主会话审核：无论结论是"采纳 IQN/q9"还是"维持 3 分位数"，均需主会话最终拍板（探索不绕过变更流程）。
