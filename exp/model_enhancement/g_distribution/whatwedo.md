# G 完整分布输出（IQN / 分位数网格）· 探索标记（whatwedo.md）

- **标记时间**：2026-08-10 12:30（东八区）
- **任务**：G 完整分布输出（exp/model_enhancement/g_distribution/）
- **背景**：M1 目前只输出 3 个分位数（p10/p50/p90），CRPS 用分段线性 CDF 近似。假设换**完整预测分布**（隐分位数网络 IQN / 更多分位数）可能让 CRPS 更优（更精确的分布估计）。这是方向 G 的开放性问题：完整分布 vs 3 分位数，CRPS 提升多少？值得改架构吗？
- **探索依据**：exp/EXPLORATION_POLICY.md（文件级探索标记）；同一滚动窗口协议（训练 730d/测试 90d/步长 45d，17 窗口，增量 abs_delta 口径，复用 B7 run_b7.py）
- **方法**：H100（sensecore）同一协议下对比 3 变体 × 3 seed：
  - `base3`：冻结 RamsNet p10/p50/p90 分位数头（B1/B2/B7 基线，CRPS 用 B7 分段线性闭合形式）
  - `q9`：简版候选——9 个固定分位数（pinball 损失，分段线性 CRPS 9 结），隔离"分位数点数"效应（如果 q9 与 iqn 差距小 → 增益主要来自分位数点数而非 IQN 的 τ 采样机制）
  - `iqn`：候选——IQN 隐分位数网络（余弦 τ 嵌入 + 共享 GRU 骨干，训练采 K=32 τ，预测采样 N=64 分位数重建 CDF，CRPS 能量形式精确估计 + PIT 校准）
- **约束**：不触碰 rams/ 冻结代码（仅 import 复用 SharedGRU/M2Head/M4Head）；新头/损失在 exp/g_distribution/ 内实现；3 seed；数据涉密只输出统计量
- **产物**：
  - `run_g.py`（实验脚本，冒烟通过）
  - `trydoing.jsonl`（执行日志）
  - `rethinking.md`（思考记录，含实证）
  - `lossing.md`（边界决策记录）
  - `results.md`（结论）
  - `results.json`（统计量，无原始数据）
- **合规**：只输出聚合统计量（覆盖/CRPS/RMSE/PIT），不打印原始数据行；不对数据/模型做任何修改（探索只动 exp/g_distribution/）
- **状态**：✅ 探索完成（2026-08-10 14:10，H100 全量 17 窗口 × 3 变体 × 3 seed × 30 epoch，20.9 分钟）
- **结论摘要**：完整分布输出（IQN）让 CRPS 提升 2.8%（iqn 0.8659 vs base3 0.8912，p<0.0001，配对 82% 改善），但收益主要是"分位数点数"效应——base3→q9（3→9 固定分位）即 +2.0%（p=0.009），q9→iqn（连续 τ 采样）仅 +0.85%（p=0.29 不显著）。iqn 的独特价值在**分布校准**：PIT 近乎均匀（[0.188,0.210,0.199,0.215,0.188]）、覆盖 0.812（窗口 std 0.075，比 base3 0.087 低 14%）、RMSE 持平（1.789 vs 1.774）。建议低成本采纳 q9（9 固定分位）拿 2/3 收益；IQN 仅在需要完整概率输出（预警/风险分位）时采纳。详见 results.md。
