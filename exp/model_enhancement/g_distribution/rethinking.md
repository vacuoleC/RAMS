# G 完整分布输出（IQN / 分位数网格）· 思考记录（rethinking.md）

## 任务意图
M1 目前只输出 3 个分位数（p10/p50/p90），CRPS 用分段线性 CDF 近似。假设换完整预测分布（隐分位数网络 IQN 或混合密度网络 MDN）可能让 CRPS 更优——更精确的分布估计。开放性问题：完整分布 vs 3 分位数，CRPS 提升多少？值得改架构吗？

## 关键设计决策

1. **候选选型（IQN 优先，MDN 备选）**：
   - **IQN（隐分位数网络）**：输入随机 τ~U(0,1)，输出该分位数的值。训练时采样多个 τ（pinball 损失逐 τ 平均），预测时采样 N 个分位数重建 CDF，CRPS 用能量形式精确估计。这是对"分位数模型"最自然的扩展（M1 本来就是分位数头）。
   - MDN（混合密度网络）：输出高斯混合参数（均值/方差/权重），CRPS 有解析近似。但需要假设分布族（高斯混合），且对 conc 有 242 个零值（min=0）的数据，高斯假设在低浓度段不自然；还要处理分量坍缩。
   - **决策：优先 IQN**。理由：(a) 对现有分位数架构最自然；(b) 无需分布族假设；(c) 训练损失（pinball）与现有分位数损失同源，风险低。
   - **加一个 q9 简版对照**：9 个固定分位数（pinball 损失 + 分段线性 CRPS 9 结）。作用是**隔离"分位数点数"效应**：如果 q9 ≈ iqn，说明增益主要来自更多分位数点而非 IQN 的 τ 连续采样机制；如果 iqn 明显优于 q9，说明连续 τ 采样（IQN）有独立价值。这决定"采纳"时的实现成本。

2. **CRPS 口径必须自洽**：
   - base3：B7 的 crps_quantiles 闭合形式（分段线性 CDF，5 结含外推）——与 B7/B2 基线同口径，可比。
   - q9：同一分段线性闭合形式的推广（任意结数）——与 base3 同族，只是结更多。
   - iqn：**能量形式 CRPS** = E|X−y| − ½E|X−X'|，对 N=64 个等权分位数点的经验 CDF **精确**（不是近似）。这是"完整分布"评估的正统做法。
   - 三者都在 conc 单位、同一测试段上比较，尺度一致可比较。

3. **持久化口径**：abs_delta 零变化 = conc_t（同 B7），CRPS 相对技能 >0 模型更优。3 变体持久化 CRPS 相同（同一口径），直接比模型 CRPS 即可。

4. **覆盖率口径**：真实 conc 落在 [p10,p90]。iqn 直接用 τ=0.1/0.9 求值（不是从网格插值），与 base3/q9 同口径。

5. **PIT 校准（iqn 专属）**：真实值在 N 个分位数中的秩（平分并列）应 ~U(0,1)。5 分箱直方图 + 逐视界 PIT 均值。PIT 均匀说明分布估计校准良好（除了点预测精度外，"分布形"对不对）。

6. **3 seed**：探索政策要求。base3 用 run_b7 内部 Trainer（模块级 SEED 需按 seed 覆盖）；q9/iqn 用 run_g 内 train_model（显式 seed）。seed 间取均值报告，附带 seed 间波动信号。

## 预期与反预期
- **预期 1**：iqn 的 CRPS 略优于 base3（更精确的分布 → CRPS 估计更准），但提升幅度可能不大——因为 3 分位数分段线性近似对"分布形状"的捕捉已经不错，CRPS 对分位数数的敏感度有限。
- **预期 2**：q9 介于 base3 与 iqn 之间（更多结 → 更精确 CDF），但可能与 iqn 接近——若如此，说明"分位数点数"是主要驱动，IQN 的连续 τ 采样机制收益有限，改架构（IQN）不值得，换"更多分位数头"（q9）即可。
- **预期 3**：iqn 的 PIT 更接近均匀（分布形更好），但 CRPS 收益可能被**训练噪声**抵消——IQN 训练时每样本采 32 个 τ 是随机近似，pinball 梯度噪声比固定分位数大，30 epoch 可能不够收敛。
- **反预期**：若 iqn 的 CRPS **差于** base3，说明在 24h 预测、conc 低自相关高噪声的目标上，随机 τ 采样的 IQN 训练不稳定，完整分布输出没有带来收益，维持 3 分位数即可。
- **反预期 2**：若 iqn 在 h1（最易）视界收益大、h4-5（最难）无收益，说明完整分布只在中短期有信息增益。

## 边界（lossing.md 对应）
- 本探索的"原方案"是 M1 分位数输出（冻结架构）。IQN/q9 若显著更好，是**对 M1 头的增量替换**（共享骨干不变，M2/M4 不变），不改变整体架构意图（GRU 骨干 + 多任务），符合原方向。
- 若 IQN 收益 <2%，不值得改架构——结论是维持 3 分位数，避免引入复杂度和训练不稳定。
- 采纳需走标准变更流程（hash→freeze）或用户批准，探索不绕过。

## 超参备忘
- 训练：30 epoch、batch 128、lr 1e-3、w_m1=1 / w_m2=3 / w_m4=2（与冻结 Trainer 一致）
- iqn：训练采 K=32 τ、预测采样 N=64 分位数、τ 余弦嵌入维 64（N_COS=64）、MLP 隐层 64
- q9：9 个固定分位数 [0.05,0.10,0.20,0.35,0.50,0.65,0.80,0.90,0.95]

## 执行后实证（2026-08-10 H100 全量 17 窗口 × 3 变体 × 3 seed × 30 epoch，20.9 分钟）

**核心结论：完整分布输出让 CRPS 提升 2.8%（显著），但收益主要是"分位数点数"效应（2/3），IQN 的连续 τ 采样机制增量不显著（1/3）。**

1. **CRPS：iqn 最优 0.8659，比 base3 提升 2.8%（p<0.0001，配对 82% 样本改善）**。逐视界全部 8 视界一致提升（+2.3%~+4.8%），h1 收益最大、h4-5 中期收益最小。q9 提升 2.0%（p=0.009）。
2. **收益分解（关键）**：base3→q9（3→9 固定分位数）= +1.99%（显著，p=0.009）；q9→iqn（连续 τ 采样）= +0.85%（不显著，p=0.29）。**2/3 的 CRPS 收益来自"更多分位数点数"，IQN 机制的独立贡献不显著**。
3. **IQN 的独特价值在分布校准，不在 CRPS 增益**：
   - PIT 校准近乎完美：[0.188, 0.210, 0.199, 0.215, 0.188] ≈ 均匀；逐视界 PIT 均值 0.500-0.503。
   - 覆盖率 0.812（11/17 窗口比 base3 更接近 80%）、覆盖窗口 std 0.075（比 base3 0.087 低 14%）。
4. **RMSE 持平**：1.774 / 1.777 / 1.789（差 <1%），分布输出不损失点精度。
5. **反预期核对**：
   - 预期 1 应验：iqn 略优于 base3，但幅度温和（2.8%）。
   - 预期 2 应验：q9 ≈ iqn 的大头，点数效应为主。
   - 预期 3 部分应验：iqn 的 PIT 更好（分布形更准），但 CRPS 的独立增量被训练噪声掩盖（p=0.29）。
   - 反预期 1 未发生：iqn 未差于 base3（30 epoch 足够收敛，loss 从 6.7 → 1.1）。

**决策相关**：本探索的"原方案"是 M1 分位数输出。Q1 答案 = 完整分布 vs 3 分位数 CRPS 提升 2.8%（iqn）/ 2.0%（q9）；Q2 答案 = 值得改，但**低成本采纳 q9（9 固定分位）**即可拿 2/3 收益，IQN 只在需要完整概率输出（预警/风险）时才值得其复杂度。详见 results.md。
