- **核心发现**：
  1. 任务书先验被证伪：2021-04-07 的"尖峰"实为表层传感器间歇掉零（深层 1-10m 真实高位 55-70）；全数据"表层孤立虚高尖峰"（S>p99 且 1-3m<p50）= 0。
  2. 垂直联动是真实事件必要特征（表层超阈值 86% 整层联动）而非区分器；持续时长是真正判别维度（p99 极端值全瞬时，真藻华持续数天~数月）。
  3. 给出可计算事件定义（顶层带中位数>p90 + 0-5m ≥3 层联动 + 持续≥2 天 + 间隔≤24h 合并）。
  4. 全数据 12 事件 / 159.9 藻华日；2021 占 74%（单一连续藻华季 3 月底-7 月初）；2023 次峰。
  5. 前置窗口（低谷→事件触发）12-27 天（中位 19.5 天）。
