# L: 采样尺度 vs 藻类过程尺度 · 思考记录（rethinking.md）

## 任务意图
当前正式模型用 3h 采样（T=24=3 天回看 → H=8=24h 视界）。M5（PCMCI+，12h 网格）证明藻类过程是
**天级到周级**：自相关翻倍 1-3 天、降水滞后 13-20 天、风 20-29 天。本实验检验核心假设：

**3h 对天级过程是过采样** —— 相邻 3h 高度相关（3h 网格 lag1 自相关≈0.90），T=24 窗口只装 3 天，
装不下天级过程完整周期；H=8 视界 24h 只覆盖不到一次翻倍。降采样到日级 + 拉长视界（30 天回看 /
7 天视界）可能：
1. 更匹配过程尺度，模型相对持久化技能更高；
2. 气象弱信号在日级重新浮现（D 的 wind_u 证伪是在 3h 尺度 + 24h 视界下做的）。

## 关键设计决策
1. **唯一差异 = 采样尺度 / 回看 / 视界**，其余协议（增量 abs_delta 目标、RamsNet 分位数 + M2/M4
   多任务、30 epoch、3 seed）完全复用 B7/D：
   - `3h`   ：T=24 → H=8（视界 24h），直接复现 B7/D base，作跨尺度对照锚
   - `12h`  ：T=24（回看 12 天）→ H=4（视界 48h），M5 用过的网格
   - `1D`   ：T=30（回看 30 天）→ H=7（视界 168h/7 天），主候选，藻华预警需要的提前量
   - `1D_wind`：1D 基础上 + wind_u 通道，看气象信号是否在日级浮现
2. **公平性（约束要求）**：各尺度滚动窗口按实际天数对齐——同一日历起始日，训练 730 天 / 测试
   90 天 / 步长 45 天，17 窗口。训练/测试切分按"预测末端日期 < 训练截止日期"（各尺度训练量、
   测试量按实际天数一致），不按行数切（行数会因尺度不同而不同）。
3. **日级聚合用均值**（resample('1D').mean()），12h 用均值（约束要求）。
4. **wind_u 先算再聚合**：wind_u = wind_speed × cos(deg2rad(wind_dir)) 在 3h 网格上逐时刻算，
   再日级均值聚合（风向是环形量，先转 u 分量避免对角度取均值；与 M5 完全一致）。
5. **持久化技能为跨尺度可比的核心指标**：skill = (CRPS_persist − CRPS_model)/CRPS_persist。
   因为各尺度视界时长不同，CRPS 绝对值不可直接比（3h h8 的 CRPS 天然含多步累积），但"相对各自
   持久化（Δ≡0 → conc_{t+h}=conc_t）的技能"可直接比，回答"哪个尺度模型相对最强"。
6. **补充跨尺度对照**：相同实际提前量（24h）下 3h h8 / 12h h2 / 1D h1 的 CRPS/RMSE——直接回答
   "日级长视界是否比 3h 短视界更有预警价值"。

## 指标口径（复用 B7/D）
- 目标：Δ = conc_{t+h} − conc_t，窗口训练段 std 归一化；评估还原 conc 单位。
- CRPS：p10/p50/p90 分位数闭合解，还原 conc 单位。
- RMSE：p50 还原 conc 单位；覆盖率 [p10,p90]。
- 持久化：Δ=0 → conc_{t+h}=conc_t（各尺度同口径）。

## 预期与反预期
- 若 1D 技能 > 3h 技能（如 +28% vs +21%）→ 日级更匹配过程尺度，假设成立。
- 若 1D 技能 ≈ 或 < 3h → 3h 的精细时序对增量预测仍有价值，日级只是"平滑后变简单"（持久化
  也变难/变易），需要看持久化 CRPS 的变化。
- 12h 介于两者之间（M5 已用它做过因果分析）。
- 1D_wind vs 1D：若 CRPS 显著降 → 气象信号在日级浮现（D 的 3h 证伪不适用于日级）；若 ≈ 或更差
  → 气象信号在日级同样冗余。

## 待执行后补充
- 各尺度 CRPS/技能/RMSE/覆盖对照表
- 相同 24h 提前量跨尺度对照
- 每视界 CRPS 曲线（看 1D 在 1-7 天的增长形态）
- 逐窗口稳定性（17 窗口，3 seed 均值）
- 结论：正式模型该用哪个采样尺度 + 视界
