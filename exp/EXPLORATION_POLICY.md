# PTMv2 探索政策（Exploration Policy）

**授权日期**：2026-08-08
**授权人**：用户（东八区）
**生效范围**：整个 v2 项目（PTMv2-supervised-refactor）

## 1. 授权声明

在科研中经常出现困难问题。本授权允许在**需要冻结计划外的想法**时，不因过于保守死板而无法推进任务。

## 2. 触发条件（困难任务判定）

满足任一即可触发探索模式：
- **长时间算力任务**：任务总墙钟预计 >72 小时（含多轮接力），困阻其余任务推进
- **冻结内方案多次受阻**：冻结设计内方案尝试多次仍受阻
- **现有方案无法破解**：出现现有方案无法解决的难题

## 3. 六步流程

### 步骤 1：三次重复实验
困难任务发生时，先进行**三次重复实验**，确保不是偶然原因。之后让**主对话判断**是否需要探索。

### 步骤 2：文件级探索标记
- 对此任务进行一个**文件级探索标记**：`exp/<task>/` 目录 + `whatwedo.md` 事件记录
- 打上标记的任务视为**进入探索模式**
- 建立**专属子代理**，为每个进入探索模式的任务在 `exp/` 下建立专门文件夹
- `exp/` 及其路径下文件**遵循管理器管理**，需要 **git 原子提交**，遵循该特殊授权

### 步骤 3：思考模式
- 对失效任务及后续方向进行**思考和反思**，细化或调整
- 在该任务探索文件夹下用 **`rethinking.md`** 持久化记录思考和反思
- 特别地：如果一个困难进行了**超过 256 轮方向探索**，主动向主会话报告"当前任务过难，需要单独设置项目，交由主对话冻结该任务"
- **每 64 轮向主会话中期报告一次**（防 256 轮一次性失控）

### 步骤 4：执行模式
- 每次思考可以产生**一个或多个探索方向**
- 执行模式选择执行顺序，**逐个探索**
- 每个方向可执行 **3-5 次**（取决于方向难度；困难问题可适当增加挑战次数）
- 在该任务 **`trydoing.jsonl`** 下记录执行日志

### 步骤 5：边界决策模式
- 当存在一个方向跑通后，**不要退出探索**，先执行边界决策
- **先读取控制器内的项目任务**，确保该探索与原方向、总方向的**真实意图不相悖**
- 在探索文件夹下用 **`lossing.md`** 记录该探索对困难问题原方案的**理解偏差、效果偏差、可能的损失和损失的必须**
- 如果方向被判为**与原任务不相符**，则不应退出，而是**进入反思模式**（偏离也是探索的一部分——观察模型的思考也能得到启发）

### 步骤 6：退出模式
- 当**边界决策通过**时，将探索交给**主对话进行最终审核**；若主对话认为方案合理，将任务的探索标记关闭，该探索完成
- 当**思考模式返回尝试超时**（即 256 轮方向均无结果），将探索交给主对话进行最终审核；若主对话认为方案合理，将任务的探索标记关闭，该探索完成
- **否则，主对话没有允许之前，不得自行停掉子代理**

## 4. 文件结构

```
exp/
├── EXPLORATION_POLICY.md        # 本政策
└── <task>/                      # 每个探索任务一个文件夹
    ├── rethinking.md            # 思考模式持久化（反思/细化/方向调整）
    ├── trydoing.jsonl           # 执行模式日志（方向/尝试/结果）
    └── lossing.md               # 边界决策记录（理解偏差/效果偏差/损失）
```

## 5. 合规要求

- `exp/` 及其路径下文件遵循**管理器管理**（supervised runtime）
- 每次思考/执行/决策更新需 **git 原子提交**（与 whatwedo.md 账本同提交）
- **探索不绕过变更流程**：探索只在 `exp/<task>/` 实验，不修改 `scr/` 冻结代码；探索成功后的"采纳"仍需标准变更流程（hash→freeze）或用户批准
- **算力边界**：探索子代理 ≤64 核，不抢占主作业（E3.1/E3.2 优先）
- **触发澄清**：24h/作业上限不变；72h 指任务总墙钟（含多轮接力）
- **产出双同步（2026-08-10 固化）**：本地与算力机进度保持一致——
  - 方向一（本地 → 算力机）：代码、脚本、文档改动后即同步
  - 方向二（算力机 → 本地）：实验结果、产出报告生成后即同步
  - 工具：`python scripts/sync_sensecore.py --both`（push=本地→算力机，pull=算力机→本地，--check 查差异）
  - 子代理产出后必须同步，主会话在阶段审核时核验两边一致

## 6. 标记与关闭

- **探索标记** = `exp/<task>/` 目录存在 + `whatwedo.md` 事件记录
- **标记关闭** = 主会话（用户）审核后，删除标记 + 记录结论（`exp/` 内容保留作为审计证据）
- 关闭条件：边界决策通过 或 256 轮超时，且主对话（用户）认为方案合理
